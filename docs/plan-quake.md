# 10편 기획 — 한반도 밑

## 질문 한 줄

**한반도 밑에는 무엇이 있나.**

지진이 왜 나는지, 내진설계가 어떻고 원전이 어떤지는 다 다른 편이다.
이 편이 답하는 것은 깊이 하나다.

## 데이터부터 확인했다

9편에서 정한 순서를 그대로 지켰다. 설계 전에 데이터.

기상청(weather.go.kr)은 이 환경에서 막혀 있다. 대신 **USGS FDSN 이벤트
API**를 열어봤고, 이게 지금까지 이 채널이 다뤄본 것 중 데이터 사정이
제일 좋았다. 전 세계 카탈로그를 기계가 읽는 형식으로 주고, 무엇보다
**이벤트 종류를 직접 분류해 둔다.**

```
type = earthquake         지진
type = nuclear explosion  핵실험 — 이 창에 여섯 건
type = collapse           붕괴 — 2017년 9월 3일 폭발 뒤 한 건
```

이게 결정적이었다. 규모만 보고 골랐으면 M6.3짜리 핵실험이 '한반도
최대 지진'으로 화면에 올라갔을 것이다. 판단을 내가 하지 않고 카탈로그의
분류를 따랐다. 지진만 그리고 폭발과 붕괴는 뺐다.

## 데이터가 소재를 정해줬다

처음에는 '한반도는 지진 안전지대인가'로 잡았다가 접었다. 연대별 건수가
1970년대 7건에서 2000년대 33건으로 느는데, 이건 지진이 는 게 아니라
관측망이 좋아진 것이다. 그 단서를 붙이고 나면 편의 절반이 변명이 된다.

대신 경도별 깊이를 뽑아봤더니 교과서 그림이 그대로 나왔다.

| 경도 | 깊이 중앙값 |
|---|---|
| 143°E (일본해구) | 25km |
| 138°E | 15km |
| 134°E | 381km |
| 131°E | 545km |
| 130°E | **566km** |
| 129°E 서쪽 (한반도) | 10km |

동에서 서로 갈수록 깊어진다. 태평양판이 일본해구에서 들어가 한반도
동북쪽 밑 645km까지 내려가 있고, 거기서 지진이 난다. 한반도 자체의
지진은 10~20km 얕은 것뿐이다.

**두 가지 지진이 한 화면에 있다.** 그게 이 편이다.

## 화면이 축을 하나 더 쓴다

아홉 편 동안 화면의 축은 위도와 경도뿐이었다. 여기에 셋째가 붙는다 —
깊이.

**평면을 위에, 단면을 아래에 놓고 가로축을 공유한다.** 지도 위 진앙에서
그대로 아래로 떨어뜨리면 그 지진의 깊이가 된다. 그러려면 지도의 경도
범위와 단면의 경도 범위가 같아야 해서 `eastasia.json`(118~143°E)을
못 썼다 — 동쪽 끝이 일본해구(143.7°E)에 걸쳐 잘린다. 같은 스크립트에
창만 바꿔 `slabmap.json`을 새로 뽑았다(124~147°E, 30~47°N).

**축척이 1:1로 떨어졌다.** 가로 1000단위가 실제 2,001km, 세로 350단위가
700km다. 단위당 2.00km 대 1.99km. 단면에서 보이는 29도 기울기가 실제
기울기라, 이 채널에서 처음으로 "눈금 없이 봐도 되는 그림"이 나왔다.

**단면이 설 때 화면이 통째로 바뀐다.** 전체화면이던 지도가 1.1초에 걸쳐
위쪽 띠(545px)로 줄고, 아래에서 단면이 올라오고, 깊이선이 0에서 700km
까지 훑고 내려가며 점이 켜진다. 그 비트만 홀드가 8.5초다.

**띠를 평면에 그려둔다.** 단면은 북위 36~44도만 쓴다. 판은 위도마다
다르게 누워 있어 창 전체를 한 단면에 겹치면 규슈 밑 얕은 지진과 함경도
밑 600km가 같은 가로 위치에 찍혀 뭉갠다. 어디를 자른 것인지 평면에
점선 두 줄로 표시한다.


## 확인한 것과 계산한 것

화면 아래 고지:

> USGS 지진 목록 · 핵실험·붕괴 제외 · 단면은 북위 36~44도 (고정댓글)

**기록값** — 좌표·깊이·규모·시각 전부 USGS 카탈로그다. 이 편에서 손으로
찍은 점은 하나도 없다.

**계산값** — 해구에서 함경북도 앞바다까지 1,156km, 서울까지 1,472km.
대권거리다. 경도별 깊이 중앙값과 기울기 29도도 계산이다.

**규모는 USGS 값** — 기상청과 다르다. 경주가 USGS M5.4 / 기상청 5.8,
포항이 USGS M5.5 / 기상청 5.4다. 척도와 관측망이 달라 생기는 차이인데,
한 카탈로그 안에서 서로 비교해야 하므로 섞지 않고 USGS로 통일했다.

**문턱이 두 개** — 창 전체는 M5.5 이상만 담았다. M5.0까지 내리면 6천
건이 넘어 일본 동쪽이 새까매진다. 그런데 한반도는 M5.5 이상이 손에
꼽아서 그 상자(124~131°E, 33~43.5°N)만 M4.0까지 내렸다.

**적지 않은 것** — 서울 밑에도 그 판이 있는지는 안 썼다. 토모그래피
연구는 상부맨틀 바닥에 누운 판을 말하지만 지진 목록으로는 알 수 없고,
이 편은 지진 목록만 가지고 만든 편이다. 화면은 지진이 난 곳까지만
말한다. 마지막 자막이 '그 서쪽은 지진으로 알 수 없음'인 이유다.
