# 24편 기획 — 밀물이 하루에 한 번만 드는 곳

## 야마

**「바닷물은 하루 두 번 든다」가 전국에 맞는 말이 아니다. 포항은
1년에 만조가 538번뿐이다. 인천은 706번이다.**

23편과 같은 자료를 쓰지만 파는 것이 다르다. 그쪽은 **시각**이었고
이쪽은 **횟수**다.

## 뻔한지 검사

```
"밀물은 하루 몇 번 들까요?"
   지어낸 답: 두 번
   실제:     포항은 1년에 171번, 만조에서 다음 만조까지 하루가 넘는다
```

**추론으로 못 닿는다.** 학교에서 배우는 그림은 「달이 끌어당겨 부푼
자리가 둘, 지구가 하루 한 바퀴 도니 두 번」이다. 그 모형에는 하루
한 번이 없다.

## 몸에 닿는 수치

**538번.** 재는 자가 자료 안에 있다.

```
1년 만조 횟수     인천 706번   ·   포항 538번   → 168번 적다
만조 → 다음 만조  인천 12시간 25분 · 포항이 하루를 넘긴 것 171번
                                    그때 평균 24시간 41분
```

23편에서 이미 잰 12시간 25분이 그대로 이 편의 자가 된다.

## 어디가 그런가 — 닫힌 집합

조위관측소 51곳을 다 셌다. 만조 간격이 24시간을 넘은 횟수다.

```
171   포항        36.047N  129.384E     만조 538번
136   후포        36.678N  129.453E         571
131   울릉도      37.491N  130.914E         573
 63   묵호        37.550N  129.116E         642
 55   동해항      37.495N  129.144E         651
 46   속초        38.207N  128.594E         660
────────────────────────────────────────────────
  3   성산포 · 서귀포 · 모슬포(2)              702~703
  0   나머지 42곳                           705~706
```

**「동해안 전부」라고 하면 틀린다.** 울산(35.502N)이 0번이다. 하루가
넘는 간격이 생기는 곳은 **울산 북쪽 동해안 5곳과 울릉도**다.
제주 3곳은 2~3번뿐이라 사실상 없는 것과 같다.

**포항_구는 뺐다.** 같은 자리의 옛 관측소라 세면 두 번 세는 것이
된다. 그래서 52곳이 아니라 51곳이다.

## 보여줄 날 — 2026-06-17

```
인천   06:20 고 9.30m   12:50 저 1.30m   18:33 고 7.95m
포항   00:03 저 0.25m   15:51 고 0.54m
```

같은 날 같은 바다다. 인천은 봉우리가 둘, 포항은 하나다.

## 높이는 안 견준다

**이 편은 크기의 편이 아니다.** 포항 조차 0.29m를 인천 9m 옆에
같은 자로 그리면 납작한 선 하나가 된다. 모양을 보이려면 관측소마다
자기 그날 범위로 펴야 한다.

화면에 그렇게 적는다 — **「높이는 각자 그날 범위로 폈다 · 모양만
견준다」**. 안 적으면 두 곡선이 같은 자 위에 있는 줄 안다.

「서해 조차가 크다」로 새면 안 된다. 그건 23편에서도 접은 이야기고
누구나 안다.

### 걸음

```
1  인천 곡선이 그려진다. 봉우리 둘. 06:20 · 18:33      「하루 2번」
2  포항 곡선이 그려진다. 봉우리 하나. 15:51            「하루 1번」
3  만조에서 다음 만조까지. 인천 12시간 25분 / 포항 24시간 41분
4  지도. 관측소 51곳을 「하루 넘긴 횟수」로 칠한다.
   울산 북쪽 동해안과 울릉도만 붉다
5  1년 셈. 인천 706번 · 포항 538번                     「168번 적다」
```

**곡선은 시계가 그린다.** 23편에서 시계로 걸음을 몰아 봤으니
같은 문법을 쓴다. 다른 것은 23편이 지도 위에서 시각을 견줬고
이 편은 하루 눈금 위에서 횟수를 센다는 것이다.


**녹음은 미룬다.** ElevenLabs가 402(크레딧 없음)를 낸다. 22·23편도
아직 무음이라 이 편도 음절로 어림해 화면만 짜 둔다. 크레딧이 생기면
세 편을 한꺼번에 갈아 끼운다.

## 넘으면 안 되는 선

- 59초 이하.
- **「동해안은 다 그렇다」라고 안 쓴다.** 울산이 0번이다.
- **높이를 서로 견주지 않는다.** 각자 그날 범위로 편 값이라고
  화면에 적는다.
- **「서해 조차가 크다」로 새지 않는다.** 이 편은 횟수의 편이다.
- **닫힌 집합을 화면에 적는다.** 「조위관측소 51곳」. 포항_구는
  같은 자리 옛 관측소라 뺐다.
- **예측값이다.** 관측값이 아니라 조석예보다. 고정댓글에 적는다.
- 마무리를 질문으로 닫는다.
