# 24편 기획 — 서울에서 지하철로 가장 많이 돌아가는 두 역

## 야마

**미아와 화계는 직선으로 1.0km다. 그런데 지하철로 가면 성신여대입구
까지 내려갔다 다시 올라와서 8정거장, 9.2km다. 9.1배 돌아간다.**

## 두 번 갈아엎었다

### 첫 판 — 「수도권 전철이 수도권을 벗어난다」

「신창에서 연천까지 148km」로 잡았다가 접었다.

1. **자가 억지였다.** 「2호선 한 바퀴 47km」를 갖다 대고 화면에
   「여기서부터 이걸 자로 쓴다」고 적었다. 그건 시청자에게 하는
   말이 아니라 **작업 메모**다.
2. **주제가 뻔했다.** 천안·아산도 춘천도 아는 사람은 안다.

### 둘째 판 — 「낙성대 ↔ 남성 8정거장」

야마는 맞았는데 **답이 틀렸다.** 낙성대(2)와 남성(7)은 사당(2·4)과
이수(4·7)로 갈아타면 3정거장이다.

**OSM이 같은 역을 이름 두 개로 갖고 있었다.** 4호선 쪽은
「총신대입구 (이수)」, 7호선 쪽은 「이수」다. 이름으로만 묶으니 그
환승이 그래프에서 끊겼고, 교대·고속터미널로 8정거장 도는 길이
최단으로 나왔다.

### 그리고 노선 하나가 통째로 빠져 있었다

**우이신설선.** `network=수도권 전철`로만 받았는데 그쪽은 `ref=W`에
network 태그가 아예 없다. 그래서 1등이 또 바뀌었다 — 미아(4)와
화계(우이신설)가 진짜 1등이다.

**노선 하나가 빠지면 「가장 많이 돌아가는 길」은 통째로 거짓말이
된다.** 셈을 시작하기 전에 노선 목록부터 눈으로 확인해야 했다.

## 뻔한지 검사

```
"서울에서 지하철로 가장 많이 돌아가는 두 역은?"
   지어낸 답: 못 짓는다
   실제:     미아(4호선)와 화계(우이신설). 직선 1.0km, 지하철 9.2km
```

## 몸에 닿는 수치

**9.1배.** 재는 자가 자료 안에 있다 — **같은 두 점의 직선과 노선**을
견준 값이라 바깥에서 빌려 올 까닭이 없다.

```
미아(4) ↔ 화계(W)
  직선     1.0km
  지하철   9.2km · 8정거장     ← 9.1배
  경로  미아 → 미아사거리 → 길음 → 성신여대입구 → 정릉 → 북한산보국문 → 솔샘 → 삼양 → 화계
```

4호선과 우이신설선이 **성신여대입구 한 곳에서만** 만난다. 나란히
달리는데 건널 데가 하나뿐이라 이 값이 나온다.

## 2·3등

```
발산(5) ↔ 양천향교(9)
  직선 1.2km → 5정거장 6.8km · 5.9배
  발산 → 마곡 → 송정 → 김포공항 → 마곡나루 → 양천향교

압구정(3) ↔ 압구정로데오(수인·분당)
  직선 1.1km → 5정거장 5.0km · 4.6배
  압구정 → 신사 → 논현 → 학동 → 강남구청 → 압구정로데오
```

**3등은 이름까지 「압구정」인데 5정거장이다.** 3호선 압구정과
수인·분당선 압구정로데오 사이에 환승이 없어서 신사·논현·학동·
강남구청을 돈다.

## 어떻게 골랐나 — 겹치지 않게

한 역을 두 번 안 쓰는 것만으로는 모자랐다. 우이신설선이 들어오자
1·2·3등이 다 강북구 미아·수유·삼양이 됐다. 규칙을 둘 더 뒀다.

- **이미 쓴 역에서 3km 밖**일 것
- **이미 쓴 노선이 아닐 것**

그래서 강북(4·우이신설) · 강서(5·9) · 강남(3·수인분당)으로 갈렸다.
지도를 세 번 같은 데로 날아가지 않는다.

## 닫힌 집합

**서울 안 역 308곳에서 직선 1km 이상 떨어진 46,982쌍을 다 쟀다.**

1km를 밑에 두는 까닭은, 그보다 가까우면 걸어가는 거리라 「돌아간다」는
말이 안 서기 때문이다.

## 이름이 갈린 역을 묶는 법

```
100m 안                       무조건 같은 역
300m 안 + 이름이 서로 들어감   같은 역 (괄호 설명만 다른 것)
```

둘째 조건이 필요한 까닭은 **송정과 공항시장이 274m**라서다. 이름이
안 겹치므로 안 묶인다. 반대로 「의정부」와 「경전철의정부」는 278m인데
이름이 겹쳐 묶인다. 이렇게 21곳이 묶였다.

**괄호 안을 지우면 안 된다.** 처음에 이름에서 괄호를 털고 견줬더니
「총신대입구 (이수)」와 「이수」가 여전히 안 묶였다. 같은 역이라는
단서가 바로 그 괄호 안에 있다.

## 급행을 걸러야 한다

이름에 「급행」이 든 계통은 역을 건너뛰어 이어져 있다. 정거장 수를
세려면 완행이어야 한다.

## 거리는 직선이다

역과 역을 대권거리로 이은 값이라 선로 길이가 아니다. 노선 거리도
정거장 사이 직선을 더한 값이라 실제보다 짧다. **둘을 같은 방식으로
쟀으니 비(比)는 성립하지만** 절대값은 계산값이라고 밝힌다.

**소요 시간은 안 쓴다.** 시간표 자료가 없다. 정거장 수가 그 자리를
대신한다.

## 화면

### 0프레임이 완성된 그림

노선망이 호선 색으로 이미 다 그려져 있고 미아·화계 두 점이 붙어
있다. 훅 글자는 타이핑 없이 다 보인다.

### 훅은 질문이다

```
직선으로 1.0km
지하철로는?
```

### 걸음

```
1  두 역에 바짝 붙는다. 점선 직선 하나.     「두 역 사이 직선 1.0km」
2  카메라가 빠지고 도는 길이 한 정거장씩.   「8정거장 · 9.2km」
3  같은 그림에 배수를 얹는다.               「9.1배」
4  2등 발산 ↔ 양천향교                      「5정거장 · 6.8km」
5  3등 압구정 ↔ 압구정로데오                「5정거장 · 5.0km」
```

**도는 길은 한 정거장씩 그린다.** 한꺼번에 띄우면 고리가 그냥
선이다. 지나가는 것을 봐야 「돌아간다」가 몸에 붙는다.

### 선은 호선 색으로 칠한다

**사람들이 노선도에서 이미 외운 색이다.** 2호선이 초록이 아니면
그 순간 지도가 아니라 그림이 된다. 색은 `src/data/lines.ts`에 있다.

한 구간을 여러 노선이 같이 쓰면 1~9호선을 먼저 두고 광역 노선이
다음이다(`LINE_ORDER`).

**도는 길에 어두운 테를 깔았다.** 강조색이 3호선 주황·인천2 주황과
겹쳐 보여서, 밑에 배경색 굵은 선을 한 겹 깔았다.

### 호선 아이콘

이름표 옆에 노선 배지를 붙인다. 숫자 노선은 동그라미, 이름 노선은
알약이다. **붙이고 나니 「4호선」이라고 글자로 다시 쓸 필요가
없어졌다.**

`U`를 우이신설로 잘못 짚었다가 고쳤다 — `U`는 의정부경전철이고
우이신설은 `W`다.

### 이름표가 두 번 겹쳤다

1등 쌍은 화면에서 가깝게 붙어 있다.

1. 가로로 밀었다 — 왼쪽 역은 이름표를 왼쪽에, 오른쪽 역은 오른쪽에.
2. 아이콘 줄이 붙으면서 **세로로 다시 겹쳤다.** 왼쪽 역은 점 아래,
   오른쪽 역은 점 위로 갈랐다.

### 마무리는 질문으로 연다

```
서울 안 역 308곳 · 1km 넘게 떨어진 46,982쌍
여러분 동네에도 이런 데 있나요?
```

## 넘으면 안 되는 선

- 59초 이하.
- **노선 목록을 먼저 눈으로 센다.** 하나가 빠지면 최단 경로가
  통째로 거짓말이 된다. `network` 태그 하나만 믿지 않는다.
- **같은 역이 이름 두 개로 갈려 있는지 본다.** 환승이 끊기면
  돌아가는 길이 실제보다 길게 나온다.
- **작업 메모를 화면에 쓰지 않는다.** 자는 말없이 대는 것이다.
- **자를 억지로 만들지 않는다.** 자료 안에 자연히 있는 자가 없으면
  그 편은 야마가 틀린 것이다.
- **거리는 계산값이라고 적는다.**
- **급행 계통을 빼고 센다.**
- **닫힌 집합을 화면에 적는다.**
- **1·2·3등을 자리와 노선으로 갈라 뽑는다.** 안 그러면 세 번 다
  같은 동네다.
- 마무리를 질문으로 닫는다.
