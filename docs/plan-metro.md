# 24편 기획 — 서울에서 지하철로 가장 많이 돌아가는 두 역

## 야마

**낙성대와 남성은 직선으로 1.1km다. 그런데 지하철로 가면 사당·서초·
고속터미널을 돌아 8정거장, 10.8km다. 9.9배 돌아간다.**

## 첫 판을 접었다

처음엔 「수도권 전철이 수도권을 벗어난다 — 신창에서 연천까지 148km」로
잡았다. 두 군데서 무너졌다.

1. **자가 억지였다.** 「2호선 한 바퀴 47km」를 갖다 대고 「여기서부터
   이걸 자로 쓴다」고 화면에 적었다. 그건 시청자에게 하는 말이 아니라
   **작업 메모**다. 그리고 무엇을 재든 2호선을 끌어오는 것은 자료
   안의 자가 아니라 형식만 채운 장치였다.
2. **주제가 뻔했다.** 천안·아산까지 간다는 것도, 춘천도, 아는 사람은
   안다. 「어디까지 가나」는 놀랍지가 않다.

같은 자료로 다시 팠다. 남은 것은 노선망뿐이고 야마는 완전히 바뀌었다.

## 뻔한지 검사

```
"서울에서 지하철로 가장 많이 돌아가는 두 역은?"
   지어낸 답: 못 짓는다. 강남 어디? 강 건너?
   실제:     낙성대(2호선)와 남성(7호선). 직선 1.1km, 지하철 10.8km
```

**답을 짐작할 수가 없다.** 추론으로도 못 닿는다 — 노선도를 외운
사람이라도 모든 쌍을 재 보지 않으면 나오지 않는 값이다.

## 몸에 닿는 수치

**9.9배.** 재는 자가 자료 안에 있다 — **같은 두 점의 직선과 노선**을
견준 값이라 바깥에서 자를 빌려 올 까닭이 없다.

```
낙성대(2호선) ↔ 남성(7호선)
  직선     1.1km
  지하철  10.8km · 8정거장     ← 9.9배
  경로  낙성대 → 사당 → 방배 → 서초 → 교대 → 고속터미널 → 내방 → 이수 → 남성
```

## 2·3등

```
6.9배  미아사거리(4) ↔ 월곡(6)     직선 1.6km  → 11정거장 11.0km
       미아사거리 → 길음 → 성신여대입구 → 한성대입구 → 혜화 → 동대문
       → 동묘앞 → 창신 → 보문 → 안암 → 고려대 → 월곡

5.9배  발산(5) ↔ 양천향교(9)       직선 1.2km  → 5정거장 6.8km
       발산 → 마곡 → 송정 → 김포공항 → 마곡나루 → 양천향교
```

**한 역은 한 번만 쓴다.** 안 그러면 낙성대·남성·사당·이수가 서로
얽혀 같은 자리 이야기가 세 번 나온다. 실제로 2위와 3위 자리에
「남성 ↔ 사당」(7.1배)과 「남성 ↔ 서울대입구」(5.8배)가 있었다.

## 닫힌 집합

**서울 안 역 317곳에서 직선 1km 이상 떨어진 49,741쌍을 다 쟀다.**

1km를 밑에 두는 까닭은, 그보다 가까우면 걸어가는 거리라 「돌아간다」는
말이 안 서기 때문이다. 화면에도 이 조건을 적는다.

## 급행을 걸러야 한다

이름에 「급행」이 든 계통은 역을 건너뛰어 이어져 있다. 정거장 수를
세려면 완행이어야 한다.

## 거리는 직선이다

역과 역을 대권거리로 이은 값이라 선로 길이가 아니다. 노선 거리도
정거장 사이 직선을 더한 값이라 실제보다 짧다. **둘을 같은 방식으로
쟀으니 비(比)는 성립하지만** 절대값은 계산값이라고 밝힌다.

**소요 시간은 안 쓴다.** 시간표 자료가 없어서 「몇 분」을 못 잰다.
정거장 수가 그 자리를 대신한다.

## 화면

### 0프레임이 완성된 그림

서울 남부 노선망이 이미 다 그려져 있고 낙성대·남성 두 점이 붙어
있다. 훅 글자는 타이핑 없이 다 보인다.

### 훅은 질문이다

```
직선으로 1.1km
지하철로는?
```

### 걸음

```
1  두 역에 바짝 붙는다. 점선 직선 하나.        「두 역 사이 직선 1.1km」
2  카메라가 빠지고 도는 길이 한 정거장씩 그려진다.
                                              「8정거장 · 10.8km」
3  같은 그림에 배수를 얹는다.                  「9.9배」
4  2등 미아사거리 ↔ 월곡                       「11정거장 · 11km」
5  3등 발산 ↔ 양천향교                         「5정거장 · 6.8km」
```

**도는 길은 한 정거장씩 그린다.** 한꺼번에 띄우면 고리가 그냥
선이다. 지나가는 것을 봐야 「돌아간다」가 몸에 붙는다.

### 선은 호선 색으로 칠한다

**사람들이 노선도에서 이미 외운 색이다.** 2호선이 초록이 아니면
그 순간 지도가 아니라 그림이 된다. 색은 `src/data/lines.ts`에
모아 뒀다.

한 구간을 여러 노선이 같이 쓰면 하나를 골라야 한다. 1~9호선을
먼저 두고 그다음 광역 노선 차례다(`LINE_ORDER`).

**도는 길에 어두운 테를 깔았다.** 강조색(#F2603C)이 3호선 주황·
인천2 주황과 겹쳐 보여서, 밑에 배경색 굵은 선을 한 겹 깔아 어느
색 위에 얹혀도 뜨게 했다.

### 호선 아이콘

이름표 옆에 노선 배지를 붙인다. 숫자 노선은 동그라미, 이름 노선은
알약이다. 실제 노선도가 그렇게 생겼고, **붙이고 나니 「2호선」이라고
글자로 다시 쓸 필요가 없어졌다.**

### 이름표가 두 번 겹쳤다

1등 쌍은 화면에서 50px밖에 안 떨어진다.

1. 처음에는 가로로만 밀었다 — 왼쪽 역은 이름표를 왼쪽에, 오른쪽
   역은 오른쪽에.
2. 아이콘 줄이 붙으면서 이름표가 높아져 **세로로 다시 겹쳤다.**
   왼쪽 역은 점 아래, 오른쪽 역은 점 위로 갈랐다.

### km은 소수 한 자리로

3등이 1.16km인데 1등이 1.1km이라 자릿수가 섞였다. 화면에 쓰는
값은 다 한 자리로 맞춘다.

### 마무리는 질문으로 연다

```
서울 안 역 317곳 · 1km 넘게 떨어진 49,741쌍
여러분 동네에도 이런 데 있나요?
```

## 넘으면 안 되는 선

- 59초 이하.
- **작업 메모를 화면에 쓰지 않는다.** 「이걸 자로 쓴다」는 시청자에게
  하는 말이 아니다. 자는 말없이 대는 것이다.
- **자를 억지로 만들지 않는다.** 자료 안에 자연히 있는 자가 없으면
  그 편은 야마가 틀린 것이다.
- **거리는 계산값이라고 적는다.** 정거장 사이 직선을 더한 값이지
  선로 길이가 아니다.
- **급행 계통을 빼고 센다.** 정거장 수를 말하려면 완행이어야 한다.
- **닫힌 집합을 화면에 적는다.** 「서울 안 역 317곳 · 1km 넘게
  떨어진 49,741쌍」.
- **한 역을 두 번 쓰지 않는다.** 순위가 같은 자리 이야기로 채워진다.
- 마무리를 질문으로 닫는다.
