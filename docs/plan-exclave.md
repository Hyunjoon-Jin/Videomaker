# 18편 기획 — 자기 시·군과 안 붙어 있는 마을

## 야마

**이웃 동네와는 땅이 붙어 있는데 자기 시·군과는 안 붙은 마을이
4곳 있다. 제일 멀리 떨어진 곳은 안산시 대부도 — 안산 본토까지
7.75km, 안산시 땅의 34%다.**

제일 넓은 곳은 대구 달성군 다사읍·하빈면 74.74km²다. 2.85km 떨어져
있고 그 사이는 전부 고령군과 달서구 땅이다.

## 기준을 세우는 데 네 판을 썼다

이 편의 제일 약한 자리가 기준이었다. 물음이 올 때마다 고쳤다.

**① 넓이 순** — '얼마나 큰 땅인가'에는 답하지만 '그래서 뭐가
불편한가'에는 답을 못 한다.

**② 도로 거리** — OSRM으로 재니 당진시가 25.9km로 세긴 셌는데,
매립지 도로망에 경로가 붙어 크게 우회해 그려졌고 점선과 실선이
한 화면에 있으니 무엇을 보는 그림인지 흐려졌다. 직선 하나로 돌아왔다.

**③ 「섬은 뺐다」** — 화면과 어긋났다. **대부도는 섬인데 이 편에
들어 있다.** 섬이냐 아니냐를 가른 적이 없다.

**④ 「방조제가 땅이냐」** — 남은 9곳 중 다섯이 새만금 방조제(군산
2.11km²)·평택당진항 매립지(0.59·0.97km²)·광양만 매립지(2.59km²)·
해남 쪽 완도군 매립지(1.19km²)였다. 넓이는 방조제 폭이 넓어서 나온
값이고 지도에서는 바다 위 띠로 보인다. **저건 땅이 아니라 구조물이다.**

그래서 마지막 기준이 이것이다.

```
이웃 동네와는 붙어 있는데
자기 시·군과는 안 붙은 마을
4곳
```

'마을'이 방조제를 걸러내고, '이웃 동네와는 붙어 있는데'가 흑산도를
걸러낸다. 한 문장에 둘이 다 들어 있다.

## 사람이 사는지는 OSM에 묻는다

넓이 컷오프 같은 임의의 선을 안 긋는다. 조각 안에 마을(place)·
주거지(landuse=residential)·아파트(building)가 있는지 본다.

```
                넓이   마을  주거지  아파트
달성군       74.74km²    22     40    304
안산시       57.78km²    13     20     21
완주군       33.61km²    19    214     58
인천 중구    14.77km²    44     16    135
─────────────────────────────────────────
광양시        2.59km²     0      0      0
군산시        2.11km²     0      0      0
완도군        1.19km²     0      0      0
당진시        0.97km²     0      0      0
평택시        0.59km²     0      0      0
```

깨끗하게 갈린다. 받아온 것은 `data/osm-exclave-place.json`에 남긴다.

## 왜 이 소재인가 — 기준 4번을 통과했다

> **묻는다** — 우리나라 시·군 중에 땅이 두 조각으로 갈라진 곳이 있나?
> **지어낸 답** — 섬이면 몰라도 육지는 없겠지.
> **실제** — 사람이 사는 마을만 세도 4곳이다. 대구 달성군은
>   74.7km²에 마을 22개가 갈라져 있고, 그 사이 2.85km는 전부
>   고령군과 달서구 땅이다.

한 번 더 거른다.

> **묻는다** — 그래봐야 귀퉁이 조각 아닌가?
> **실제** — 안산시는 **땅의 34%**(대부도 57.78km²)가 본토와 안 붙어
>   있다.

## 몸에 닿는 수치가 셋이다 — 자가 다 자료 안에 있다

```
7.75 km    안산 대부도에서 안산 본토까지
  34 %     그게 안산시 땅에서 차지하는 몫
74.74 km²  제일 넓은 곳(달성군 다사읍·하빈면), 달성군 땅의 18%
```

바깥에서 여의도 같은 것을 빌려 오지 않는다. 17편에서 배운 것이다.

## 확인한 것 — 4곳

```
             떨어진 거리       넓이   그 시·군 땅의   사이
경기 안산시      7.75km   57.78km²      33.7%   바다 6.43 · 화성시 1.32
전북 완주군      3.38km   33.61km²       4.1%   전주시 3.38
대구 달성군      2.85km   74.74km²      17.7%   고령군 2.35 · 달서구 0.5
인천 중구       1.81km   14.77km²      10.3%   바다
```

### 안 센 것

```
1,049곳   이웃 시·군과 아예 안 닿는 덩어리 (흑산도·돌산도·교동도·연평도)
    5곳   이웃과는 닿지만 사람이 안 사는 것 (방조제·항만 매립지)
```

**백령도와 울릉도는 아예 안 걸린다.** 옹진군·울릉군에서 제일 넓은
덩어리, 곧 그 군의 나머지 땅 자체다. 점으로 찍어 확인했다.

```
  백령도  옹진군  1/64위   51.02km²   나머지 땅 자체
  울릉도  울릉군  1/4위    72.90km²   나머지 땅 자체
  흑산도  신안군  12/218위 23.74km²   이웃과 안 닿음 → 안 셈
```

### 첫 판정이 11곳이었던 이유

세 가지를 고쳤다.

**① 단위를 시·군·자치구로 되돌렸다.** 일반구(안산시 상록구·단원구,
전주시 덕진구·완산구)를 시로 합쳤다. 합치니 안산이 뒤집혔다 —
단원구만 보면 본토 쪽이 떨어진 땅이지만, 상록구와 합치면 본토가
나머지 땅이 되고 대부도가 떨어진 땅이 된다.

**② 붙었다고 보는 거리를 하나로 맞췄다.** 자기 덩어리끼리는 60m,
남의 시·군과는 150m로 재고 있었다. 부산 강서구(가덕도)가 그 자리에
있었고, 150m 하나로 맞추니 사라졌다.

**③ 이름만으로 묶지 않는다.** '동구'는 여섯 곳에 있고 고성군은 둘이다.
시도 코드까지 붙여 묶는다. 빠뜨렸을 때 강원 고성군과 경남 고성군이
한 시·군이 되면서 '516km² 월경지'가 나왔다.

## 말

**어려운 말을 안 쓴다.**

```
본체            → 그 시·군의 나머지 땅
조각            → 떨어진 땅
사이에 낀 남의 땅 → 사이에 낀 남의 동네
월경지           → 안 쓴다 (태그에만 남긴다)
섬              → 안 쓴다 (대부도가 반례다)
```

## 화면

### 무엇이 그림인가

**세 색과 점선 하나, 그리고 이름표.**

```
빨강    떨어진 땅        「달성군 떨어진 땅」
쪽빛    그 시·군의 나머지 땅  「달성군」
흙색    사이에 낀 남의 동네  「고령군」「달서구」
점선    떨어진 거리 — 그어지며 뻗는다
```

### 이름표

색만 칠해두면 **어느 게 어디 땅인지 알 수가 없다.** 한 번 그렇게
내보내고 바로 걸렸다.

나머지 땅은 이름만 적는다. '달성군 나머지 땅'까지 적으면 글자가
화면 밖으로 밀린다. 떨어진 땅 쪽에 '떨어진'이 붙어 있으니 나머지가
무엇인지는 그것으로 갈린다.

**자리는 격자로 고른다.** 폴리곤 무게중심을 쓰면 화면 밖으로
나가거나 바다 위에 앉는다. 보이는 상자를 90×90으로 훑어 그 땅
안에 드는 점만 모으고, 계기판과 자막이 덮는 위아래를 뺀 다음,
남은 점들의 가운데에 가장 가까운 점을 고른다.

글자 크기는 화면 기준으로 고정한다. 지도 좌표로 두면 카메라가
붙을 때마다 간판만 해진다.

### 글자를 걷어냈다

이름표를 달고 나니 화면에 같은 말이 두 번씩 있었다.

```
뺀 것
  범례 3줄            이름표에 '떨어진 땅'이 이미 적혀 있다
  「사이 — 바다 6.43km」  지도에 색과 이름이 있다
  자막 넉 줄           '부안 옆에 붙은 군산시 땅'은 이름표 두 개와 같은 말
  기준 화면의 설명 넉 줄
  마무리 표 머리       마지막 한 줄과 같은 말
```

남긴 자막은 **지도와 계기판이 둘 다 못 주는 것**뿐이다 — 읍·면 이름,
섬 이름.

### 순서

훅(2.2초) → 기준(2.6초) → 4걸음(28.2초) → 마무리(8.0초). 41.00초.

떨어진 거리가 짧은 것에서 긴 것으로.

```
인천 중구   1.81km   14.77km²   ← 나머지 땅이 영종도
대구 달성군  2.85km   74.74km²   ← 제일 넓은 곳
전북 완주군  3.38km   33.61km²   ← 사이가 전부 전주
경기 안산시  7.75km   57.78km²   ← 절정. 대부도, 안산 땅의 34%
```

### 계기판

```
경기 안산시
7.75 km                    ← 제일 크게. 첫 걸음에만 옆에 '떨어진 거리'
57.78km² · 안산시의 33.7%
```

### 마무리

4곳 표. 시·군 이름 · 떨어진 거리 · 넓이. 그 아래 한 줄 —
**코앞인데 남의 동네를 지나야 하는 마을 4곳.**

## 제목

```
같은 시 땅인데 7.75km 떨어져 있는 곳이 있습니다
```

- 대안: `이웃 동네와는 붙어 있는데 자기 시와는 안 붙은 마을이 4군데 있습니다`
- 달성군을 앞세운 것: `대구 달성군은 땅의 18%가 자기 군과 안 붙어 있습니다`

## 썸네일

**안 만든다.** 14편부터 따로 뽑지 않는다.

## 데이터

**경계** — `data/skorea-municipalities.json`. 통계청 2018년 시군구
경계 250개.

**사람** — OSM(maps.mail.ru Overpass 거울). 조각 안의 마을·주거지·
아파트. `data/osm-exclave-place.json`에 남긴다.

판정은 넷이다.

```
① 나머지 땅 = 넓이가 가장 큰 덩어리      (점 수로 고르면 틀린다)
② 떨어진 땅 = 그것과 안 붙은 것
③ 이웃과 맞닿을 것 = 다른 시·군과 150m 안으로
④ 사람이 살 것     = 마을·주거지·아파트가 있을 것
```

## 넘으면 안 되는 선

- **화면에 '섬'이라고 쓰지 않는다.** 대부도가 반례다.
- **'육지에 붙어 있는'도 쓰지 않는다.** 방조제와 매립지가 지도에서
  바다 위 띠로 보여 말과 그림이 어긋난다.
- **거리는 직선이다.** 실제 도로로는 더 멀다.
- **'사람이 산다'는 OSM 기준이다.** 마을·주거지·아파트가 자료에
  들어 있는지를 본 것이지 인구를 센 것이 아니다. 고정댓글에 밝힌다.
- **왜 갈라졌는지 단정하지 않는다.** 법령 원문을 못 봤다.
- **'4곳'은 이 경계 자료 기준이다.** 읍·면 단위는 안 잡힌다.
- **넓이는 계산값이다.** 안산시 합계가 171.3km²로 나오는데 공식
  면적은 155.7km²다 — 시화호 수면이 경계 안에 들어 있어서다.
- **'걸어서 못 간다'고 쓰지 않는다.** 다리가 놓인 곳이 있다.
- **'인천 남구'는 지금 미추홀구다.** 2018년 7월에 바뀌었고 이 경계
  자료는 그 전 이름을 쓴다. 고정댓글에 밝힌다.
