# 접었다 — 자기 시·군과 안 붙어 있는 땅

**기준을 다섯 번 고쳐 썼고 그때마다 목록이 줄었다.** 11곳 → 9곳 →
4곳 → 2곳. 볼 때마다 예외가 나왔고 그때마다 규칙을 하나씩 더
붙여야 했다.

```
① 넓이 순                    11곳 → 9곳
② 도로 거리                  화면이 흐려져 되돌림
③ 「섬은 뺐다」               대부도가 반례라 폐기
④ 「저 다리는 다리지 땅이냐」    9곳 → 4곳  (방조제·매립지)
⑤ 「대부도는 섬 아니냐」         4곳 → 2곳  (사이가 바다)
```

2곳으로는 편이 안 선다. **규칙을 다섯 개 쌓아야 성립하는 야마는
야마가 아니다.** 같은 자료로 규칙이 하나뿐인 편을 다시 잡았다 —
`docs/plan-span.md`(같은 시·군의 이 끝에서 저 끝까지).

여기서 잰 값은 그 편에 그대로 쓰인다. 아래는 접기 전 기록이다.

---

## 야마

**걸어서 갈 수 있는데, 가는 길이 전부 남의 동네인 땅이 전국에
딱 2곳 있다.**

```
대구 달성군  다사읍·하빈면  74.74km²  달성군 땅의 18%
             2.85km 떨어져 있고 그 사이는 고령군 2.35km · 달서구 0.5km

전북 완주군  이서면 쪽      33.61km²  완주군 땅의 4%
             3.38km 떨어져 있고 그 3.38km가 전부 전주시
```

## 기준을 다섯 판 고쳐 썼다

이 편의 제일 약한 자리가 기준이었다. 물음이 올 때마다 고쳤고,
그때마다 목록이 줄었다.

**① 넓이 순 (11곳→9곳)** — '얼마나 큰 땅인가'에는 답하지만
'그래서 뭐가 불편한가'에는 답을 못 한다.

**② 도로 거리** — OSRM으로 재니 당진시가 25.9km로 세긴 셌는데,
매립지 도로망에 경로가 붙어 크게 우회해 그려졌다. 점선과 실선이
한 화면에 있으니 무엇을 보는 그림인지 흐려졌다. 직선 하나로 돌아왔다.

**③ 「섬은 뺐다」** — 화면과 어긋났다. **대부도는 섬인데 이 편에
들어 있다.** 섬이냐 아니냐를 가른 적이 없다.

**④ 「저 다리는 다리지 땅이냐」 (9곳→4곳)** — 남은 아홉 중 다섯이
새만금 방조제(군산 2.11km²)·평택당진항 매립지(0.59·0.97km²)·
광양만 매립지(2.59km²)·해남 쪽 완도군 매립지(1.19km²)였다. 넓이는
방조제 폭이 넓어서 나온 값이고 지도에서는 바다 위 띠로 보인다.
**저건 땅이 아니라 구조물이다.** OSM에 물어 마을·주거지·아파트가
있는 것만 남겼다.

**⑤ 「대부도는 섬 아니냐」 (4곳→2곳)** — 맞다. 시화방조제로 시흥시와
이어져 있을 뿐이고, 안산 본토와 안 붙은 이유는 행정이 아니라
시화호다. 인천 중구도 같다 — 나머지 땅이 영종도라서 갈라진 것이다.
**바다 때문에 갈라진 것은 이 편의 이야기가 아니다.**

그래서 마지막 기준이 이것이다.

```
걸어서 갈 수 있는데
가는 길이 전부 남의 동네
2곳
```

이 한 문장이 셋을 다 걸러낸다.

```
'걸어서 갈 수 있는데'   → 흑산도 같은 섬 1,049곳이 빠진다
'가는 길'              → 사람이 안 사는 매립지 5곳이 빠진다
'전부 남의 동네'        → 바다로 갈라진 2곳이 빠진다
```

**섬 이야기를 아예 안 해도 된다.** 화면에 '섬'이라는 말이 한 번도
안 나온다.

## 판정 다섯

```
① 나머지 땅 = 넓이가 가장 큰 덩어리        (점 수로 고르면 틀린다)
② 떨어진 땅 = 그것과 안 붙은 것
③ 이웃과 맞닿을 것 = 다른 시·군과 150m 안으로
④ 사람이 살 것     = 마을·주거지·아파트가 있을 것 (OSM)
⑤ 사이에 바다가 없을 것 = 최단선이 전부 남의 시·군 땅 위를 지날 것
```

### ④를 자료로 가른다

넓이 컷오프 같은 임의의 선을 안 긋는다.

```
                넓이   마을  주거지  아파트
달성군       74.74km²    22     40    304
안산시       57.78km²    13     20     21
완주군       33.61km²    19    214     58
인천 중구    14.77km²    44     16    135
─────────────────────────────────────────
광양시        2.59km²     0      0      0
군산시        2.11km²     0      0      0
완도군        1.19km²     0      0      0
당진시        0.97km²     0      0      0
평택시        0.59km²     0      0      0
```

### ⑤를 자료로 가른다

최단선을 200등분해 각 점이 어느 시·군 안에 드는지 본다.

```
                 사이
대구 달성군   고령군 2.35km · 달서구 0.5km      ← 전부 땅
전북 완주군   전주시 3.38km                     ← 전부 땅
─────────────────────────────────────────
경기 안산시   바다 6.43km · 화성시 1.32km       ← 바다
인천 중구     바다 1.81km                       ← 바다
```

### 안 센 것

```
1,049곳   이웃 시·군과 아예 안 닿는 덩어리 (흑산도·돌산도·교동도·연평도)
    5곳   이웃과는 닿지만 사람이 안 사는 것 (방조제·항만 매립지)
    2곳   사람은 살지만 사이가 바다인 것 (대부도·인천 중구 내륙)
```

**백령도와 울릉도는 아예 안 걸린다.** 옹진군·울릉군에서 제일 넓은
덩어리, 곧 그 군의 나머지 땅 자체다. 점으로 찍어 확인했다.

## 왜 이 소재인가 — 기준 4번을 통과했다

> **묻는다** — 우리나라 시·군 중에 걸어서 자기 시·군 땅을 밟고는
>   못 가는 마을이 있나?
> **지어낸 답** — 섬이면 몰라도 육지는 없겠지.
> **실제** — 딱 2곳. 대구 달성군 다사읍·하빈면 74.7km²는 달성군
>   땅의 18%인데, 자기 군으로 가려면 고령군과 달서구를 지나야 한다.

## 몸에 닿는 수치가 셋이다 — 자가 다 자료 안에 있다

```
74.74 km²  달성군 다사읍·하빈면, 달성군 땅의 18%
 2.85 km   자기 군 땅까지 — 그 사이가 전부 남의 동네
    6 곳   그 땅을 둘러싼 시·군·구
```

## 훅

```
전국 2곳

74.7km²

같은 군 땅인데 안 붙어 있는 곳
```

'걸어서 못 가는 곳'이라고 쓰지 않는다. 남의 땅을 밟으면 걸어서
갈 수 있다. 못 가는 것은 **자기 군 땅만 밟고**다.

## 화면

### 세 색과 점선 하나, 그리고 이름표

```
빨강    떨어진 땅        「달성군 떨어진 땅」
쪽빛    그 시·군의 나머지 땅  「달성군」
흙색    사이에 낀 남의 동네  「고령군」「달서구」
점선    떨어진 거리 — 그어지며 뻗는다
```

이름표 자리는 카메라 안을 90×90 격자로 훑어 그 땅 위에서 고른다.
폴리곤 무게중심을 쓰면 화면 밖으로 나가거나 바다 위에 앉는다.
글자 크기는 화면 기준으로 고정한다.

### 눈금을 뺐다

2곳이면 막대 두 칸이라 우스꽝스럽다. 순위가 없으면 눈금도 없다.

### 순서

훅(2.2초) → 기준(2.6초) → 2걸음(18.0초) → 마무리(5.6초). **28.40초.**

```
대구 달성군  2.85km  74.74km²  ← 제일 넓은 곳
전북 완주군  3.38km  33.61km²  ← 사이가 전부 전주
```

### 계기판

```
대구 달성군
2.85 km                     ← 첫 걸음에만 옆에 '떨어진 거리'
74.74km² · 달성군의 17.7%
```

### 마무리

표를 뒀다가 뺐다. 두 줄짜리 표는 방금 본 두 걸음과 같은 말이다.
전국 지도에 점 둘만 남기고 한 줄로 못박는다 — **전국에 딱 2곳.**

## 제목

```
걸어서 갈 수 있는데 가는 길이 전부 남의 동네인 곳
```

- 대안: `대구 달성군은 자기 군에 가려면 남의 동네를 지나야 합니다`
- 숫자를 앞세운 것: `같은 군 땅 74.7km²가 자기 군과 안 붙어 있습니다`

## 넘으면 안 되는 선

- **화면에 '섬'이라고 쓰지 않는다.** 기준이 섬을 가르지 않는다.
- **'걸어서 못 간다'고 쓰지 않는다.** 남의 땅을 밟으면 갈 수 있다.
  못 가는 것은 자기 군 땅만 밟고다.
- **거리는 직선이다.** 실제 도로로는 더 멀다.
- **'사람이 산다'는 OSM 기준이다.** 인구를 센 것이 아니다.
- **왜 갈라졌는지 단정하지 않는다.** 법령 원문을 못 봤다.
- **'2곳'은 이 경계 자료 기준이다.** 읍·면 단위는 안 잡힌다.
- **넓이는 계산값이다.**
- **'인천 남구'는 지금 미추홀구다.** 2018년 7월에 바뀌었다.
