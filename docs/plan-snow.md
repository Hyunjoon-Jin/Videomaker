# 15편 기획 — 하루에 어른 키만큼

## 야마

**하루에 눈이 어른 목까지 온 날이 있다.**

```
울릉도  150.9cm  1955-01-20   키 170cm의 89% — 목까지
대관령   92.0cm  1992-01-31   1위의 61%
```

## 야마를 두 번 갈아엎었다

### 첫 판 — '기록은 겨울이 아니라 하루가 만든다'

92곳의 기록이 54일에 걸려 있고 2004년 3월 5일 하루가 여덟 곳을
세웠다는 것. 숫자는 다 맞았는데 **통계 문장이라 칠 통념이 없었다.**
'내 동네 기록이 몇 개 날짜에 걸려 있나'를 궁금해하는 사람이 없다.

### 둘째 판 — '눈 제일 많이 온 대도시는 대구'

서울 25.8cm(2010-01-04)를 자로 놓고 광역시 일곱을 세웠다. 야마는
섰는데 둘이 틀렸다.

- **서울 중심이다.** 자가 서울이면 편 전체가 서울을 기준으로 돈다.
- **디테일이 없다.** 막대 일곱 개와 배수뿐이라, 몇 년에 얼마나
  왔는지가 계기판에 잠깐 스칠 뿐 화면에 남지 않는다.

### 셋째 판 — 자를 사람 키로

**서울도 대관령도 아닌, 누구에게나 같은 자.** cm는 감이 안 오지만
'목까지'는 온다.

## 왜 이 소재인가 — 기준 4번을 통과했다

> **묻는다** — 하루에 눈이 제일 많이 온 곳은?
> **지어낸 답** — 대관령. 강원도 산간.
> **실제** — 울릉도다. 대관령의 1.64배.

한 번 더 걸러본다.

> **묻는다** — 그래봐야 얼마나 오나?
> **실제** — 150.9cm. 키 170cm 사람의 목까지다.

## 확인한 것 — 하루에 쌓인 눈 역대 전국 10위

```
 1위  울릉도    150.9cm  1955-01-20  키의   89%
 2위  대관령     92.0cm  1992-01-31  키의   54%
 3위  속초      89.6cm  1969-02-20  키의   53%
 4위  북강릉     77.7cm  2011-02-11  키의   46%
 5위  동해      70.2cm  2011-02-11  키의   41%
 6위  태백      70.2cm  1987-02-03  키의   41%
 7위  강릉      67.9cm  1990-01-31  키의   40%
 8위  영덕      61.0cm  2005-03-05  키의   36%
 9위  목포      51.7cm  1946-12-09  키의   30%
10위  대구      51.0cm  1953-01-18  키의   30%
```

3위부터 7위까지 다 동해안이다. 9위 목포와 10위 대구가 남쪽 도시고,
둘 다 옛날 기록이다 — 목포 1946년(해방 이듬해), 대구 1953년(전쟁 중).

## 훅

```
하루에 쌓인 눈

어디까지 왔을까
```

0프레임에 **사람과 지면이 이미 서 있다.** 자(170cm)도 걸려 있다.
훅 글자는 사람 머리 위에 둔다 — 가운데 두면 몸을 덮는다.

## 화면

### 무엇이 그림인가

**키 170cm 사람 하나와 차오르는 눈.** 10위에서 1위로 올라가며 눈이
실제 비율로 차오른다. 잠긴 부분은 눈에 가려 안 보인다.

cm를 아무리 크게 써도 감이 안 온다. 무릎 위 → 허벅지 → 허리 위 →
가슴 → 목. 몸으로 읽힌다.

### 수위선 — 디테일이 쌓인다

눈이 차오르기만 하면 앞에 뭐가 있었는지 잊는다. **지나온 자리에
가로 점선과 라벨을 남긴다** — `3위 속초 89.6cm · 1969`.

1위에 닿을 즈음 눈 속에 아홉 줄이 쌓여 있고, 그것이 '이만큼 더
왔다'를 말한다. 라벨은 값이 붙은 지점끼리 겹치므로 위(큰 값)부터
자리를 잡고 아래로 밀어낸다.

### 계기판

순위 · 지점명 다음에 **연도를 제일 크게** 쓴다. `1955` `1월 20일`.
몇 년인지가 이 편의 절반이다.

### 완급

10~7위는 2초, 위로 갈수록 길어져 1위는 6.4초. 계단이 무거워진다.

### 마무리

역대 10위 표. 순위·지점·날짜·값을 한 줄에 다 적는다. 훑고 지나간
디테일을 마지막에 한 판으로 다시 세운다.

## 썸네일

눈벽 앞에 선 사람 하나. 눈이 목까지 온다. 색면에 `1955년`.

**사람을 눈 앞에 세운다.** 본편은 눈이 차오르며 사람이 잠기는데,
썸네일에서 그대로 하면 200px에서 머리 하나만 남아 무엇인지 모른다.
과정이 없는 한 장에서는 전신이 보여야 높이가 읽힌다.

## 넘으면 안 되는 선

- **일 최심신적설과 최심적설을 섞지 않는다.** 이 자료는 하루에 새로
  쌓인 눈이다. 널리 인용되는 울릉도 293.6cm는 최심적설이라 다른 값이다.
- **170cm를 '어른 평균 키'로 말하지 않는다.** 자로 삼은 눈금이다.
- **관측 시작 연도가 지점마다 다르다.** 기간을 맞추면 1위가 대관령으로
  바뀐다. 고정댓글에 밝힌다.
- **원인을 단정하지 않는다.** '동해를 건너며 수증기를 먹는다'는
  교과서 설명이고 이 자료로 증명한 것이 아니다. 상위 일곱 곳이
  동해안이라는 사실만 적는다.
- 2004년 3월 폭설 등 개별 사건의 피해 규모는 원자료를 못 봤다.

## 접은 가설 — 기록으로 남긴다

**'눈은 높은 데가 아니라 바닷가에 쌓인다.'** 전체 기간으로 재면
그럴듯했다.

```
1위 울릉도 150.9cm  해발 221m
2위 대관령  92.0cm  해발 772m
상위 8곳 중 6곳이 해발 100m 아래 (속초 17m, 강릉 27m, 동해 41m …)
적설 ~ 해발고도 상관 +0.31
```

**관측 기간을 맞추자 뒤집혔다.** 1973년 이전에 시작한 61곳만 골라
1973~2026 구간으로 다시 재면 이렇게 된다.

```
1위 대관령  92.0cm      적설 ~ 해발고도 상관 +0.42
2위 울릉도  88.9cm      해발 200m 이상 13곳 평균 42.5cm
3위 속초   80.6cm      해발 100m 미만 65곳 평균 28.0cm
```

**높은 곳에 더 온다.** 데이터가 반대였으므로 접었다. 13편에서 양평과
홍천이 갈렸던 것과 같은 함정이다.

## 쓰지 않은 것

첫 판에서 낸 것들이다. 편에는 안 들어갔지만 자료는 남아 있다.

- 92곳의 기록이 54일에 걸려 있고, 둘 이상 겹친 17일이 55곳(60%)을 만든다
- 2004년 3월 5일 하루가 여덟 곳의 역대 1위를 세웠다
  (대전·문경 49.0, 보은 39.9, 영주 35.8, 청주 32.0, 상주 30.6,
  부여 29.8, 안동 27.0) — 4일 밤 경기에서 시작해 5일 충청·경북으로 내려갔다
- 지점별 1위가 난 달: 11월 3곳, 12월 21곳, 1월 33곳, 2월 22곳, 3월 13곳
