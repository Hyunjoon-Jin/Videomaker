# KT 수도권강남법인고객본부 상반기 직책자 워크샵 — 오프닝 영상 통합 제작 가이드

**총 러닝타임: 약 2분 40초 (PART 1 뉴스 속보 70초 + PART 2 야구 경기 90초)**

이 문서는 씬 순서대로 읽으면서 그대로 제작하는 구조입니다. 각 씬마다 **콘티(무엇을) → 프롬프트(무엇으로) → 검수(뽑고 나서) → 편집(어떻게 붙일지)**이 한 세트로 묶여 있습니다.

# 0. 시작 전 공통 원칙 (전 씬 적용)

## 0-1. 제작 안전 원칙

- 정상 축전에 등장하는 인물은 **실존 정치인이 아닌 가상의 패러디 캐릭터**로 제작합니다. 실존 인물과 닮지 않게, 국가명도 가상("아메리카나 합중국", "유로피아 연방")으로 처리해 누가 봐도 유머 코드임이 드러나게 합니다. 생성 결과물이 실존 인물과 닮았다면 폐기 후 외모 키워드를 바꿔 재생성합니다.
- 부문장님 등장 컷은 실촬영이든 AI 아바타든 **본인 사전 동의 필수**입니다.
- BGM·SFX는 라이선스 프리 음원(Artlist, Epidemic Sound 등)만 사용합니다.

## 0-2. Veo 프롬프트 공통 원칙

프롬프트 구조는 항상 이 순서로:

```
[샷 타입 + 카메라 움직임] + [피사체 묘사] + [단 하나의 동작] +
[배경/환경] + [조명] + [스타일 레퍼런스] + [금지 요소]
```

- **1클립 = 1동작.** 동작을 연결하면 반드시 깨집니다. 동작을 쪼개서 여러 클립을 뽑고 편집에서 잇습니다.
- **클립 길이는 8초.** 콘티의 "20초 몽타주"는 8초 클립 3~4개를 편집으로 조립하는 것입니다.
- **모든 프롬프트 끝에 금지 문구 고정:** `no text, no letters, no logos, no captions, no watermarks, no scoreboard numbers`. Veo가 그리는 글자는 100% 깨지므로 텍스트는 전부 후반에서 얹습니다.
- **테이크는 컷당 최소 3~4회 생성.** 전체 기준 약 25컷 × 3테이크 = 75회 생성이 현실적인 예산입니다.
- **프레임 안 인물은 3명 이하.** 인원이 많아지면 팔다리가 섞입니다.
- **손 클로즈업 최소화.** 손이 꼭 나와야 하는 컷(Scene 12-C)은 별도 표기했으며 최다 테이크가 필요합니다.
- **유니폼 통일:** 우리 팀 = `navy blue and white uniform`, 상대 팀 = `grey and dark red uniform`. 실존 구단과 닮지 않게 가상 디자인 유지.
- **야구 특화:** 공을 와이드샷으로 추적 금지(공 소실·복제 빈발). 공은 ①타격 초슬로모 클로즈업 ②하늘 궤적 단독샷으로만 뽑고 중간은 리액션 컷으로 대체. 투구·스윙 폼은 `professional MLB-level mechanics` 명시.
- **인물 일관성:** 같은 인물이 여러 컷에 필요하면 이미지 생성으로 캐릭터 시트를 만들어 image-to-video로 시작 프레임 고정. 유니폼 색 통일만으로도 편집상 같은 팀으로 읽힙니다.

## 0-3. HeyGen 공통 설정

립싱크가 필요한 컷(Scene 2, 3, 4, 그리고 Scene 5 백업안)은 HeyGen 담당입니다. HeyGen은 **아바타 + 보이스 + 대본 + 출력 설정** 4가지 조합으로 결과가 결정됩니다.

| 항목 | 설정 | 이유 |
|---|---|---|
| 배경 | Green Screen (#00FF00) | Premiere Ultra Key로 따서 Veo 배경 위 합성 |
| 해상도 | 1080p 이상, 16:9 | 시퀀스 규격 일치 |
| 자막 기능 | OFF | 자막은 AE에서 통일 폰트로 직접 제작 |
| 프레이밍 | 미디엄샷 (허리 위) | 클로즈업일수록 립싱크 어색함 노출. 미디엄샷 + 하단 대형 자막이 안전 조합 |
| 대본 | 문장마다 마침표, 호흡 지점에 `<break time="0.5s">` | 한국어 TTS는 쉼 태그가 자연스러움의 80% |
| 생성 후 | 외래어·고유명사 발음 검수 | 10초 테스트 생성 후 전체 생성 |

**발음 치환표 (대본 입력 시 이대로):** B2B → 비투비 / KT → 케이티 / 워크샵 → 워크숍(보이스별 양쪽 테스트)

## 0-4. 프로젝트 셋업

| 항목 | 스펙 |
|---|---|
| 시퀀스 | 3840×2160 (Veo 출력 1080p면 1920×1080), 23.976fps, Rec.709 |
| 폴더 | `01_Veo원본` / `02_선별테이크` / `03_HeyGen` / `04_실촬영` / `05_SFX_BGM` / `06_AE컴프` / `07_출력` |
| 파일명 | `S07A_take03.mp4` (씬번호+프롬프트버전+테이크) — 테이크가 수십 개 쌓이므로 처음부터 규칙 고정 |

**작업 순서 (권장):** ① 내레이션·멘트를 TTS 가데모로 전부 녹음해 타임라인에 먼저 배치(전체 길이 확정 — 영상을 오디오에 맞추는 게 역방향보다 훨씬 빠릅니다) → ② Veo/HeyGen 생성·선별 → ③ 컷 편집 + 속도 램프 → ④ AE 그래픽(Dynamic Link) → ⑤ 사운드 → ⑥ 컬러 → ⑦ 출력. **중간 컨펌은 ②~③ 단계의 임시 컷 상태에서 상무님께 한 번 받는 것을 강력 추천** — 완성 후 구조 수정은 비용이 3배입니다.

## Scene 2 — AI 앵커 브리핑 (완성 20초)

### 콘티

| 항목 | 내용 |
|---|---|
| 화면 | 뉴스 스튜디오, 앵커 데스크 미디엄샷. 배경 대형 스크린에 도시/빌딩 그래픽 |
| 하단 자막바 (AE) | 상단(빨강): "속보" / 하단(흰색): "전 세계 B2B 업계 초긴장… 강남·서부, 하나로 뭉쳤다" |

**앵커 멘트:**
> "속보입니다. 오늘, 수도권강남법인고객본부의 직책자 워크샵이 전격 개최됐습니다. 작년 각자의 리그에서 최고의 성과를 기록했던 강남법인과 서부법인이 올해 하나의 팀으로 뭉치면서, 전 세계 B2B 업계가 긴장하고 있다는 소식입니다. 이 역사적인 워크샵을 앞두고, 세계 각국 정상들도 축하 메시지를 보내왔습니다. 화면으로 만나보시죠."

### 제작 방식
앵커의 20초 립싱크는 Veo가 아니라 **HeyGen 아바타**로 만들고, Veo는 배경과 인서트 컷만 담당합니다.

### HeyGen 세트

**아바타 — 옵션 A(권장):** 스톡 아바타 중 한국인/동아시아계 + 정장 + 뉴스룸 톤 선택 (스톡이 제스처·시선이 가장 안정적).
**옵션 B(커스텀) 생성 프롬프트:**
```
Professional Korean female news anchor in her mid 30s, neat shoulder-length
black hair, wearing a sharp light grey blazer over a white blouse, subtle
professional makeup, confident and trustworthy expression, sitting upright
facing camera, plain studio background, broadcast news presenter style
```
(남성 앵커: `mid 40s Korean male news anchor, short neat black hair, navy suit with a blue tie`)

**보이스:** 한국어 뉴스/포멀 계열, 속도 1.0, 스타일 Serious/Professional.

**대본 (그대로 입력):**
```
속보입니다. <break time="0.3s">
오늘, 수도권 강남법인고객본부의 직책자 워크숍이 전격 개최됐습니다. <break time="0.5s">
작년, 각자의 리그에서 최고의 성과를 기록했던 강남법인과 서부법인이 <break time="0.3s">
올해 하나의 팀으로 뭉치면서, <break time="0.3s">
전 세계 비투비 업계가 긴장하고 있다는 소식입니다. <break time="0.7s">
이 역사적인 워크숍을 앞두고, <break time="0.3s">
세계 각국 정상들도 축하 메시지를 보내왔습니다. <break time="0.5s">
화면으로 만나보시죠.
```

### Veo 프롬프트

**A — 앵커 뒤에 깔 스튜디오 배경:**
```
Empty modern broadcast news studio, sleek anchor desk in foreground,
large wall screen behind showing abstract blue city skyline graphics,
cool blue and white studio lighting, static camera, wide shot,
no people, no text, no letters, no logos
```

**B — 멘트 중간 인서트(자료화면):**
```
Cinematic aerial shot of a modern glass office tower district at dusk,
golden window lights, slow drone push-in, corporate documentary style,
no text, no letters, no logos
```

### 편집
- **합성:** HeyGen 그린스크린 출력 → Ultra Key → Veo 스튜디오 배경 위 배치. 앵커 하반신이 데스크에 가려지는 구도로 잡으면 크롭 어색함이 사라집니다.
- **타임라인:** 앵커 6초 → 인서트 B컷 4초(멘트 지속) → 앵커 6초 → "화면으로 만나보시죠"에서 화이트 플래시 전환.
- **사운드:** 뉴스룸 앰비언스(키보드·웅성거림) -25dB로 깔면 현실감 급상승.

## Scene 3 — 가상 정상 축전 ① 아메리카나 합중국 대통령 (완성 12초)

### 콘티

| 항목 | 내용 |
|---|---|
| 화면 | 가상 국기(오렌지·퍼플 줄무늬)의 웅장한 집무실, 과장되게 자신만만한 가상 대통령 캐릭터 |
| 네임택 (AE) | "아메리카나 합중국 대통령 (가상)" — '(가상)' 표기는 안전장치이자 그 자체로 개그 |

**축전 멘트:**
> "강남법인고객본부의 워크샵 개최를 축하합니다. 트레멘더스! 지난해 강남과 서부가 보여준 성과는 그레이트, 정말 그레이트했습니다. 하반기, 여러분이 만들 성과가 벌써 기대됩니다!"

### 제작 방식 (투트랙 중 택1)
- **옵션 ① HeyGen 아바타(권장):** 립싱크 정합. 배경은 Veo 집무실 합성 또는 HeyGen 내장 클래식 집무실 (위성 프레임을 씌우면 배경 디테일은 묻히므로 내장 배경도 무방).
- **옵션 ② Veo 인물 클립 + 더빙:** 예능 톤이므로 립싱크 불일치를 하단 대형 자막으로 커버하는 방식도 성립.

### HeyGen 세트 (옵션 ①)

**아바타 생성 프롬프트:**
```
A fictional comedic national leader character, original character not
resembling any real politician: heavyset man in his 60s, completely bald
head, round face, thick grey eyebrows, wearing a navy blue suit with an
oversized long red tie, sitting confidently with shoulders back, big
friendly grin, plain background, slightly exaggerated caricature-like
but photorealistic style
```

**보이스:** 한국어 중저음 남성, 힘 있고 과장 가능한 톤, 속도 0.95(거물 느낌), 스타일 Cheerful/Confident.

**대본 (그대로 입력):**
```
강남법인고객본부의 워크숍 개최를 축하합니다. <break time="0.5s">
트레멘더스! <break time="0.7s">
지난해 강남과 서부가 보여준 성과는, <break time="0.3s">
그레이트, 정말 그레이트했습니다. <break time="0.5s">
하반기, 여러분이 만들 성과가 벌써 기대됩니다. <break time="0.5s">
원더풀!
```
> 영어 감탄사는 한글로 입력해야 어색한 언어 전환 없이 읽습니다. 발음이 뭉개지면 "트레멘더스" → "정말 엄청납니다!"로 교체해도 개그는 유지.

### Veo 프롬프트 (옵션 ② 인물 클립 / 또는 옵션 ①의 배경용)

```
Medium shot, static camera: a fictional cartoonishly confident national
leader — an original character, heavyset middle-aged man with grey short
hair (NOT resembling any real politician), navy suit, long red tie —
sitting at an ornate gold-trimmed presidential desk, speaking to camera
with big enthusiastic hand gestures, thumbs up at the end,
grand office with dark wood panels and a fictional flag with orange and
purple stripes on a pole behind him, warm cinematic lighting,
slightly comedic exaggerated tone, no text, no letters, no logos
```

### 검수 (이 씬 최우선)
- **실존 정치인 유사성 확인.** 특정 인물이 연상되면 폐기 후 외모 키워드 교체 (`bald` → `full head of white curly hair`, `add thick moustache` 등).
- 국기가 성조기처럼 나오면 재생성 (`orange and purple stripes` 강조).

### 편집
- **위성 중계 연출 (Part 1의 핵심 치트키):** 화면 네 귀퉁이에 "LIVE - SATELLITE" 프레임 + 약한 노이즈/글리치 → 뉴스 위성 중계 느낌이 살면서, AI 특유의 미묘한 어색함이 전부 '위성 화질' 핑계로 덮입니다.
- 더빙 사용 시(옵션 ②) 하단 1/3 대형 자막으로 시선을 자막에 고정 — 예능식 립싱크 커버 기법.
- 네임택 "아메리카나 합중국 대통령 (가상)" AE 삽입.

## Scene 4 — 가상 정상 축전 ② 유로피아 연방 총리 (완성 12초)

### 콘티

| 항목 | 내용 |
|---|---|
| 화면 | 대리석 기둥의 유럽풍 고전 집무실, 가상 국기(파랑 바탕 금색 월계수), 차분하고 품위 있는 가상 총리 |
| 네임택 (AE) | "유로피아 연방 총리 (가상)" |

# 마무리. 후반작업 통합 가이드

## 컬러 (Veo 클립 톤 통일)

- Veo는 클립마다 색온도가 제각각 → Lumetri **조정 레이어 하나에 통합 그레이드**(틸-오렌지 약간, 컨트라스트 +10, 채도 -5)로 전체를 묶고, 개별 클립은 화이트밸런스만 미세 보정.
- PART 2는 추가 조정 레이어로 나이트 게임 룩(섀도우 블루, 하이라이트 웜) 통일 — 조명 색만 맞아도 다른 소스가 한 경기처럼 보입니다.
- Scene 10만 채도 -20 (침체 강조).

## 사운드 체크리스트

| 요소 | 소스 | 비고 |
