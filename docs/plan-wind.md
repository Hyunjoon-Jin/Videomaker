# 16편 기획 — 관측 이래 가장 센 바람

## 야마

**우리나라에 불었던 가장 센 바람은 초속 63.7m, 시속 229km다.
2006년 10월 23일 속초.**

강풍경보 기준(순간풍속 26m/s)의 **2.45배**이고, 고속도로를 달리는
차(100km/h)의 두 배가 넘는다.

## 왜 이 소재인가 — 기준 4번을 통과했다

> **묻는다** — 우리나라에서 제일 센 바람이 분 곳은?
> **지어낸 답** — 제주. 태풍 매미 때.
> **실제** — 속초다. 매미가 세운 2위(제주 60.0)보다 세고,
>   태풍철도 아닌 10월이었다.

**몸에 닿는다.** 63.7m/s는 감이 안 오지만 시속 229km는 온다.

## 확인한 것 — 관측 이래 5위

```
1위  속초    63.7m/s   229km/h   2006-10-23   관측시작 1968
2위  제주    60.0m/s   216km/h   2003-09-12   관측시작 1923
3위  고산    60.0m/s   216km/h   2003-09-12   관측시작 1988
4위  흑산도  58.3m/s   210km/h   2000-08-31   관측시작 1997
5위  울릉도  52.4m/s   189km/h   2007-09-17   관측시작 1938
```

- **2·3위는 같은 값, 같은 날, 같은 섬이다.** 60.0m/s 동률이고
  둘 다 제주도이며, 2003년 9월 12일은 태풍 매미 상륙일이다
  (3편에서 확인한 값, `src/data/typhoon.ts`).
- 5위 안에 **섬이 셋**(제주·고산·흑산도·울릉도 중 넷이 섬이거나
  섬 지점)이고, 육지는 속초뿐이다.

## 자 — 어느 정도 세기인가

두 가지로 잰다. **둘 다 원문을 확인한 값이다.**

### ① 시속

```
 26 m/s =  94km/h   강풍경보 기준(순간풍속)
100km/h            고속도로를 달리는 차
229km/h            속초 2006-10-23     ← 이 편
305km/h            KTX 영업 최고속도
```

### ② 강풍특보 기준의 몇 배

기상청 강풍특보 기준(kma.go.kr 예보 안내)에서 원문을 받았다.

```
주의보  풍속 14m/s 이상  또는  순간 20m/s 이상
경보    풍속 21m/s 이상  또는  순간 26m/s 이상
```

이 자료가 **최대순간풍속**이므로 '순간 20 / 순간 26' 쪽과 바로
맞물린다. 섞어 쓰는 값이 아니다.

```
속초 63.7  =  경보 기준(순간 26)의 2.45배
울릉도 52.4 =  2.02배
```

## 데이터

기상자료개방포털 기후통계 극값 조회. 15편과 같은 창구다.

```
POST data.kma.go.kr/climate/extremum/selectExtremumAjaxList.do
  schGubun=1  schElem=2(최대순간풍속)  schStnId=<지점번호>
→ 그 지점의 역대 상위 10건 (값·날짜·관측시작일)
```

지점을 비우면 전국 상위 10건만 나와 닫힌 집합이 안 된다. 96개
지점을 하나씩 다 돌려 `data/kma-wind.json`에 받아뒀다. 96곳 전부
기록이 있다.

## 화면

### 무엇이 그림인가

**지도가 지점으로 날아가 확대된다.** 5위에서 1위로, 한 곳씩.

지금까지 편들은 전국 지도가 고정이었다. 이 편은 지도 자체가
움직인다 — 울릉도로 갔다가 흑산도로, 제주로, 마지막에 속초로.

### 섬이 보여야 한다

`provinces.json`은 시도 경계라 울릉도·흑산도가 최소 면적 필터에
걸려 빠져 있다(3편 주석에 기록). 클로즈업하면 빈 바다에 점 하나만
남는다.

그래서 **시군구 경계**(`data/skorea-municipalities.json`, 250개)를
같은 투영식으로 옮겨 쓴다. 울릉군·신안군이 들어 있어 섬이 그려진다.
원본이 18MB·44만 점이라 클로즈업 축척에서 읽히는 정밀도로 줄여
`src/data/wind-map.json`에 낸다.

### 한 지점에서 보이는 것

```
   5위  울릉도                    ← 순위와 이름
   52.4 m/s                       ← 관측값
   시속 189km                     ← 자 ①
   강풍경보의 2.0배                ← 자 ②
   2007년 9월 17일                ← 언제
```

**연도를 크게 쓴다.** 15편에서 배운 것이다.

### 속도 눈금 — 화면 아래 고정

지점이 바뀌어도 눈금은 그대로 있고, 값만 그 위를 옮겨 다닌다.

```
0 ──── 94(강풍경보) ──── 100(고속도로) ──── 229 ──── 305(KTX)
```

각 지점이 켜질 때 눈금 위에 표가 서고, **지나온 지점의 표는 남는다.**
15편 수위선과 같은 자리 — 디테일이 쌓여야 한다.

### 순서

1. 훅 — 전국 지도 (0프레임 완성)
2. 5위 울릉도 → 클로즈업
3. 4위 흑산도
4. 3위 고산 · 2위 제주 — 같은 날 같은 섬이라 한 화면에 묶는다
5. **1위 속초** — 제일 길게
6. 마무리 — 전국 지도로 빠지며 5위 표

**1위를 맨 뒤에 둔다.** 13편에서 배운 것이다.

## 만들면서 고친 것

- **카메라 폭을 눈으로 못 맞춘다.** 울릉도 본섬이 투영에서 10px,
  흑산도가 6px이다. 처음에 78·96으로 잡았더니 점 하나만 보였다.
  폴리곤 크기를 재서 섬이 화면 폭의 절반쯤 차지하도록 23·26으로
  내렸다.
- **작은 섬은 덜 줄여야 한다.** 전국용 톨러런스(0.22px)를 흑산도에
  그대로 먹이니 클로즈업에서 각이 졌다. 조각 넓이에 따라
  `min(TOL, √area/60)`로 바꿨다.
- **전국 뷰에서 시군구 경계선은 얼룩이다.** 카메라가 붙을수록
  경계선을 켜도록 `strokeOpacity`를 폭에 걸었다.
- **눈금 라벨이 뭉친다.** 4위 210 · 3위 216 · 2위 216이라 순위
  라벨이 겹쳤다. 왼쪽부터 훑어 34px 안에 들면 라벨을 접고 선만
  남긴다.
- **썸네일 뷰박스는 본편과 다르다.** 본편 svg는 1080×1920을
  채우지만 썸네일은 색면 위 1090px만 쓴다. 같은 식을 쓰면 지점이
  색면 아래로 잘린다.

## 넘으면 안 되는 선

- **'태풍이 아니었다'고 쓰지 않는다.** 2006년 10월 23일 속초가
  무엇이었는지 원자료를 못 봤다. 기상청 태풍 목록 페이지가 이
  환경에서 안 열린다. 날짜만 적는다.
- **최대순간풍속과 최대풍속(10분 평균)을 섞지 않는다.** 태풍 강도
  등급(중·강·매우강·초강력)은 10분 평균 기준이라 이 값과 직접
  비교하면 안 된다. 강풍특보는 순간풍속 기준이 따로 있어 그쪽만 쓴다.
- **관측 시작 연도가 지점마다 다르다.** 흑산도는 1997년, 제주는
  1923년부터다. 화면에 같이 적는다.
- **원인을 단정하지 않는다.** 양간지풍 같은 이름 붙은 국지 강풍
  이야기는 원문을 못 봤으므로 쓰지 않는다.
- 북한 지점은 빠졌다. 남한 관측망만이다.

## 접은 것 — 기록으로 남긴다

처음에는 **'제일 센 바람이 부는 계절이 지역마다 다르다'**로 잡았다.
데이터로는 정확히 참이다.

```
강원 영동·동해안 7곳 — 전부 7~9월이 아니다
  속초 10-23  울진 01-01  동해 01-01  대관령 04-21
  강릉 04-27  북강릉 04-10  태백 04-21

남해안·제주 13곳 — 목포(10-25) 하나 빼고 전부 7~9월
```

그런데 그건 **관찰이지 주장이 아니었다.** '가장 센 바람'이라는
한 점으로 좁히면 계절 이야기는 그 안에 저절로 들어온다 — 1위가
10월이라는 사실 하나로 충분하다.

자료는 `data/kma-wind.json`에 그대로 있다. 나중에 쓸 수 있다.
