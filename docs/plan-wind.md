# 16편 기획 — 제일 센 바람이 부는 계절이 지역마다 다르다

## 야마

**우리나라에서 가장 센 바람은 태풍이 오는 계절에 불지 않았다.**

```
1위  속초  63.7m/s = 시속 229km   2006-10-23
2위  제주  60.0m/s = 시속 216km   2003-09-12  (태풍 매미 상륙일)
```

그리고 이건 속초 하나의 예외가 아니다.

```
강원 영동·동해안 7곳 — 전부 7~9월이 아니다
  속초    63.7  2006-10-23      대관령  45.7  1987-04-21
  울진    51.9  1997-01-01      강릉    41.6  1983-04-27
  동해    41.3  1997-01-01      북강릉  32.1  2018-04-10
  태백    30.6  1987-04-21

남해안·제주 13곳 — 목포 하나 빼고 전부 7~9월이다
  제주 09-12  고산 09-12  흑산도 08-31  완도 08-28  여수 09-12
  통영 07-23  서귀포 08-30  성산 09-16  부산 08-31  거제 09-12
  남해 09-12  진도 09-06   /  목포만 10-25
```

**땅이 다르면 때가 다르다.** 채널 이름 그대로다.

## 왜 이 소재인가 — 기준 4번을 통과했다

> **묻는다** — 우리나라에서 제일 센 바람이 분 곳은?
> **지어낸 답** — 제주. 태풍 매미 때.
> **실제** — 속초다. 시속 229km. 그리고 10월이었다.

한 번 더 걸러본다.

> **묻는다** — 속초가 어쩌다 한 번 세게 맞은 것 아닌가?
> **실제** — 영동 일곱 곳이 전부 태풍철 밖이다. 하나도 예외가 없다.

**몸에 닿는다.** 63.7m/s는 감이 안 오지만 시속 229km는 온다.
고속도로 제한속도의 두 배가 넘고, KTX 영업속도(305km/h)의 3/4다.

## 데이터 — 받아서 확인했다

기상자료개방포털 기후통계 극값 조회. 15편과 같은 창구다.

```
POST data.kma.go.kr/climate/extremum/selectExtremumAjaxList.do
  schGubun=1  schElem=2(최대순간풍속)  schStnId=<지점번호>
→ 그 지점의 역대 상위 10건 (값·날짜·관측시작일)
```

지점을 비우면 전국 상위 10건만 나와 닫힌 집합이 안 된다. 96개
지점을 하나씩 다 돌려 `data/kma-wind.json`에 받아뒀다. 96곳 전부
기록이 있다.

### 지점별 최대순간풍속 1위가 난 달

```
 1월  2곳     7월  4곳
 2월  3곳     8월 28곳  ████████████████████████████
 3월  9곳     9월 34곳  ██████████████████████████████████
 4월  7곳    10월  3곳
 5월  1곳    11월  3곳
 6월  2곳    12월  0곳
```

7~9월이 66곳, 그 밖이 30곳이다. **전국으로 보면 태풍철이 압도적인데,
1위가 그 밖에 있다.**

## '때' — 하루가 남긴 것

같은 날 여러 곳의 1위가 몰린 날이 있다.

```
2003-09-12  14곳   대구 창원 여수 제주 고산 남원 장수 의성 영천
                   거창 합천 밀양 거제 남해        ← 태풍 매미
2012-08-28  13곳   완도 고창 순천 강화 보은 천안 부여 영광 순창
                   보성 강진 장흥 함양
1999-08-03   9곳   원주 청주 전주 광주 금산 부안 임실 정읍 해남
1997-01-01   2곳   울진 동해                        ← 새해 첫날
1987-04-21   2곳   대관령 태백                      ← 봄
```

태풍이 하루에 열넷을 만들고, 영동의 겨울 하루가 둘을 만든다.

## 넘으면 안 되는 선 — '태풍이 아니었다'고 쓰지 않는다

2006년 10월 23일 속초에 무슨 일이 있었는지, 그날이 태풍이었는지
아닌지를 **원자료로 확인하지 못했다.** 기상청 태풍 목록 페이지가
이 환경에서 안 열린다.

그래서 화면에는 **날짜만 적는다.** '10월 23일'과 '1월 1일'을 크게
띄우면 보는 사람이 스스로 안다. 단정은 안 한다.

2003년 9월 12일이 태풍 매미 상륙일이라는 것만 쓴다 — 3편에서 이미
확인한 값이다(`src/data/typhoon.ts`).

양간지풍처럼 이름이 붙은 국지 강풍 이야기도 원문을 못 봤으므로
쓰지 않는다.

## 훅

```
시속 229km

우리나라에서 가장 센 바람
```

0프레임에 지도와 속도 눈금이 이미 떠 있다.

## 화면

### 무엇이 그림인가

**계절로 칠한 지도.** 96곳을 자기 최강풍이 분 달의 색으로 칠한다.

```
7~9월   태풍 색 (주황)
그 밖   겨울·봄 색 (청록)
```

남해안과 제주가 주황으로 물들고 **강원 영동만 청록으로 남는다.**
이 한 장이 야마의 전부다. 0프레임에 이미 완성돼 있어야 한다.

### 자 — 시속

m/s는 감이 안 온다. 화면 오른쪽에 세로 속도 눈금을 세우고
기준값을 걸어둔다.

```
305 ─ KTX 영업 최고속도
229 ─ 속초
120 ─ 고속도로 최고제한
```

각 지점이 켜질 때 눈금 위 자기 자리에 막대가 선다. 15편에서
사람 키를 자로 삼은 것과 같은 자리다 — 자는 누구나 아는 것이어야 한다.

### 순서

1. 계절 지도 전체 (0프레임에 완성)
2. 남해안 — 2003년 9월 12일 하루가 14곳을 만들었다
3. 영동 일곱 — 전부 태풍철 밖. 날짜를 하나씩
4. 1위 속초 — 시속 229km, 2006년 10월 23일
5. 마무리 — 전국 10위 표

**1위를 맨 뒤에 둔다.** 13편에서 배운 것이다.

### 계기판

지점명 · m/s · **시속** · 날짜. 날짜의 '달'을 크게 쓴다 — 이 편은
달이 야마다.

## 제목

```
우리나라에서 가장 센 바람은 시속 229km, 10월이었습니다
```

- 대안: `강원 영동에서 제일 센 바람은 여름에 안 붑니다`
- 태풍을 앞세운 것: `태풍 매미보다 센 바람이 있었습니다`

첫 번째를 쓴다. 시속이 걸리고 '10월'이 통념을 친다.

## 썸네일

계절로 갈린 지도. 남쪽은 주황, 영동은 청록. 색면에 `229km/h`.

**지점 이름은 속초 하나만.** 색이 갈린 그림이 이 편의 전부라
이름을 여럿 넣으면 그 그림이 흐려진다.

## BGM

공유마당. 바람 편이라 몰아치는 쪽이되, 태풍 편(3편)의 조여드는
음악과는 갈라야 한다. 이 편은 재난이 아니라 계절 이야기다.

15편의 「12월, 광화문 거리 교향곡」과도 갈라야 한다 — 두 편 연속
같은 곡은 안 쓴다.

## 넘으면 안 되는 선

- **'태풍이 아니었다'고 쓰지 않는다.** 원자료를 못 봤다. 날짜만 적는다.
- **최대순간풍속과 최대풍속(10분 평균)을 섞지 않는다.** 태풍 강도
  등급(중·강·매우강·초강력)은 10분 평균 기준이라 이 값과 직접
  비교하면 안 된다.
- **관측 시작 연도가 지점마다 다르다.** 흑산도는 1997년, 부산은
  1904년부터다. 순위를 말할 때 밝힌다.
- **원인을 단정하지 않는다.** 영동이 왜 겨울·봄에 센지는 이 자료로
  말할 수 없다. '일곱 곳 전부 태풍철 밖'이라는 사실만 적는다.
- 북한 지점은 빠졌다. 남한 관측망만이다.
