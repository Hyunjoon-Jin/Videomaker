# 「땅과 때」 게시용 텍스트

영상마다 제목·설명·고정댓글을 함께 둔다. 고정댓글이 따로 있는 이유는,
방법과 한계를 설명란 맨 아래 적어두면 아무도 안 읽기 때문이다. 이 채널에서
제일 먼저 시비가 붙을 지점이 거기라 맨 위로 끌어올린다.

## 1. 임진왜란 7년

### 제목
```
임진왜란 7년, 일본군이 한양에 있던 건 11개월
```

### 설명
```
1592년 음력 4월 13일 부산 상륙부터 1598년 음력 11월 노량 해전까지,
7년을 지도 한 장 위에서 봅니다.

날짜는 모두 음력입니다. 한국 기록은 음력, 영어 자료는 양력이라 두 계통이
40일쯤 어긋납니다. 이 영상은 음력으로 통일하고 화면에도 그렇게 적었습니다.

- 일본군 한양 입성 1592년 5월 3일, 한양 수복 1593년 4월 18일
- 부산 상륙에서 한양 함락까지 20일
- 전투 28곳과 주요 도시는 실제 위경도를 투영한 좌표입니다
- 전라도는 1차 침공에서 끝내 뚫리지 않아 점선으로 따로 둘렀습니다

### 고정댓글
```
지도 만드는 방법을 밝혀둡니다.

전선은 기록에 남은 경유지를 이은 선입니다. 평양 함락이나 한양 수복처럼
날짜와 위치가 남은 지점은 그 좌표를 그대로 쓰고, 경유지와 경유지 사이는
제가 이었습니다. 그 사이의 잔굴곡은 실제 전선의 모양이 아니라 생성한
것이라 화면 아래에 그렇게 적어뒀습니다.

의병 표시는 점령 지역이 아니라 기병지입니다. 의병이 그 일대를 장악했다는
뜻으로 읽히면 안 되어서 채우지 않고 점만 찍었습니다.

때문입니다. 위도로만 전선을 그으면 1592년의 전라도가 점령지로 칠해지는데,
그 해에 관해 그것보다 중요한 사실이 없어서 도 단위로 다시 그렸습니다.

틀린 곳 있으면 알려주세요. 고쳐서 다시 올립니다.

## 2. 6·25 전쟁

### 제목
```
6·25, 38선에서 낙동강까지 40일
```

### 설명
```
1950년 6월 25일부터 1953년 7월 27일까지 1,128일, 전선이 어디까지
오르내렸는지를 하루 단위로 봅니다.

- 남침에서 낙동강 방어선까지 40일
- 인천상륙 9월 15일, 서울 수복 9월 28일
- 초산 도달 10월 26일, 전쟁의 최북단
- 정전 협정까지 3년 1개월, 전선은 시작한 자리로 돌아왔습니다

전선 하나로는 표현이 안 되는 것이 둘 있어 따로 그렸습니다. 흥남처럼
전선 뒤에 고립된 채 아군이 지키던 지역은 점선으로 도려냈고, 지리산과
태백산맥의 유격 지역은 점령이 아니라 활동 범위라 옅은 음영으로만 뒀습니다.

```
지도 만드는 방법을 밝혀둡니다.

전선은 문서로 남은 선에서 시작했습니다. 낙동강 방어선의 마산·왜관·영덕,
최북단의 청천강·초산·장진·혜산, 1·4후퇴 뒤의 평택·원주·삼척, 정전선의

## 3. 한국을 때린 태풍 넷

### 제목
```
1959년 추석날 온 태풍, 사망·실종 849명
```

### 설명
```
사라·루사·매미·힌남노의 경로를 같은 지도 위에 겹쳐 봅니다.

- 사라 1959년 9월 17일 남해안, 사망·실종 849명
- 루사 2002년 8월 31일 전남 고흥, 강릉 일강수량 870.5mm
- 매미 2003년 9월 12일 경남 고성, 상륙 시 955hPa
- 힌남노 2022년 9월 6일 경남 거제, 상륙 시 950hPa

기압만 보면 루사가 넷 중 제일 약합니다. 그런데 피해는 루사가 가장
컸습니다. 이유가 바람이 아니라 비였기 때문에, 중심기압과 일 최대
강수량을 나란히 놓았습니다.

원으로만 그리면 안 보이는 것이 하나 더 있습니다. 북반구 태풍은 진행
방향 오른쪽이 위험합니다. 회전풍과 태풍 자체의 이동속도가 그쪽에서
더해지기 때문입니다. 그 반원에 들어간 땅을 빗금으로 덮었습니다.

음악: "Anguish" — Kevin MacLeod (incompetech.com)
Licensed under Creative Commons: By Attribution 4.0
https://creativecommons.org/licenses/by/4.0/

#태풍 #사라 #루사 #매미 #힌남노 #기상
```

### 고정댓글
```
숫자 출처와 한계를 밝혀둡니다.

상륙 지점과 상륙 시 중심기압, 일 최대 강수량은 기록값입니다. 경로는
알려진 진로를 위경도로 옮긴 근사라, 점과 점 사이는 보간입니다. 그러니
이 영상이 특정 시각의 태풍 위치를 주장하지는 않습니다.

사라의 강수량은 비워뒀습니다. 1959년 관측망으로는 숫자를 세울 수가
없습니다. 0으로 그리면 비가 안 온 것처럼 보여서 '기록 없음'으로 뒀습니다.

사라의 849명은 이름 붙은 태풍 가운데 가장 많은 사망·실종자이고 광복
이후로도 1위지만, 전체 1위는 아닙니다. 1936년 태풍이 1,232명, 1923년
태풍이 1,157명으로 앞에 있습니다.

위험반원의 크기는 개념도입니다. 실제 강풍 반경이 아닙니다.

## 4. 한반도 철도 127년

### 제목
```
서울역에서 신의주행 표를 팔던 39년
```

### 설명
```
1899년 경인선부터 2017년 강릉선까지, 한반도에 철길이 놓인 순서를
지도 위에서 봅니다.

- 1899 경인선, 1905 경부선, 1906 경의선
- 1914 호남선과 경원선, 1928 함경선
- 1945 북으로 가던 세 노선이 한꺼번에 끊김
- 2002 도라산역, 2004 KTX

이 영상의 지표는 총 연장이 아니라 경의선의 종점입니다. 1906년 신의주에서
시작해 1945년 개성, 1953년 문산으로 내려오고, 2002년 도라산에서 멈춰
있습니다. 북위로는 40.10도에서 37.90도입니다.

북측 구간을 지우지 않고 회색 점선으로 남긴 이유는, 선로가 사라진 게
아니라 다니지 못하게 된 것이기 때문입니다.

#철도 #한국사 #역사지도 #경의선 #KTX #도라산

### 고정댓글
```
연도와 선형에 대해 밝혀둡니다.

연도는 각 노선의 전 구간 개통 기준입니다. 부분 개통은 그보다 이릅니다.
경부선은 1905년, 경의선은 1906년 4월 3일, 경원선은 1914년 9월 6일,
함경선은 1928년 9월 1일입니다. 태백선은 1973년 10월 고한과 황지가
이어지면서 함백선·정선선·고한선을 묶어 붙은 이름입니다.

지표를 '서울에서 갈 수 있는 가장 북쪽 역'이라고 하지 않은 이유가
있습니다. 도라산역은 남측 최북단 역이 아닙니다. 경원선 백마고지역이
위도상 더 위에 있습니다. 그래서 경의선 종점으로 좁혔습니다.

선형은 실제 궤도가 아니라 주요 정차역의 실좌표를 이은 근사입니다.
산을 돌아가는 실제 노선보다 짧고 곧습니다.

끊긴 경계는 두 단계로 뒀습니다. 1945년에는 38선이고, 정전 뒤에는 서부
군사분계선이 38선보다 남쪽으로 내려와 개성이 북쪽으로 넘어갑니다.
경의선을 통째로 회색으로 칠하지 않은 것도 같은 이유입니다. 분단 뒤에도
서울에서 개성까지는 다녔습니다.

틀린 곳 있으면 알려주세요. 고쳐서 다시 올립니다.
```
