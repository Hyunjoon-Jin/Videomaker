# KT 수도권강남법인고객본부 워크샵 오프닝 — 콘티 (현재안)

**컨셉:** 긴급 뉴스 속보(상반기 성과) → 프로야구 중계(경기 서사) 패러디
**메시지:** 상반기 성과를 딛고 **"이제 홈런 쳐서 하반기 역전하자!"**
**총 러닝타임:** 약 **3분 49초** (24씬) · 1920×1080 · 30fps
**팀:** 홈 = **최상강남**(KT 위즈 유니폼) / 원정 = **RIVALS**(그레이·네이비)
**스코어 서사:** 4-0 선취(상반기 성과) → 4-7 역전 허용(하반기 위기) → 8회말 2사 만루 → 결정적 타격(결과는 열어둠)

**에셋 표기:** 🎬 실제 업로드 영상 · 🖼 AI 생성 이미지+카메라 무빙 · ✏️ 코드 그래픽
