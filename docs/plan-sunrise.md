# 11편 기획 — 해가 가장 먼저 뜨는 곳

## 야마

**"해가 가장 먼저 뜨는 곳"은 한 곳이 아니다. 1년에 여섯 번 자리를 옮긴다.**

동해안을 따라 남에서 북으로 올라갔다가 다시 내려온다.

**그리고 마지막에 뒤집는다 — 사실 1등은 사철 독도다.**

간절곶도 호미곶도 정동진도 고성도, 365일 내내 한 번도 1등을 못 해봤다.
육지에서 다투는 동안 독도가 이미 4.9~10.7분 먼저 보고 있었다.

## 왜 이 소재인가 — 기준 4번을 통과했다

왕릉 편이 여기서 접혔다. 질문을 던지고 답을 지어봤을 때 지어낸 답이
실제와 같으면 편이 안 선다.

이 소재는 어긋난다.

> **묻는다** — 우리나라에서 해가 가장 먼저 뜨는 곳은?
> **지어낸 답** — 동쪽 끝. 호미곶이나 간절곶. 한 곳으로 정해져 있다.
> **실제** — 계절마다 다르다. 1년에 여섯 번 바뀐다.

경도가 이기는 계절과 위도가 이기는 계절이 따로 있다. 겨울에는 남쪽이,
여름에는 북쪽이 먼저 본다.

덤으로 오래된 다툼이 하나 풀린다. 간절곶과 호미곶이 서로 '가장 먼저
해 뜨는 곳'이라고 하는데 **둘 다 맞는 말이다.** 달이 다를 뿐이다.

## 데이터 — 전부 자체 계산

외부 자료가 필요 없다. 위경도와 날짜만 있으면 일출 시각이 나온다.
지금까지 편들이 데이터 확보에서 막혀 접힌 적이 두 번 있었는데
(영해·간척) 이 편은 그 위험이 아예 없다.

NOAA 일출 알고리즘을 쓴다. 태양 적위와 시간각을 구하고 고도 -0.833도
(대기 굴절 34분각 + 태양 반지름 16분각)를 지평선으로 잡는다.

**검산** — 서울(37.5665, 126.9780) 2026년 1월 1일 일출이 07:47로
나온다. 관측값과 같다.

## 재본 결과

동해안 네 곳으로 잡았다. 새해 해맞이 명소로 이름이 알려진 자리들이다.

| | 위도 | 경도 |
|---|---|---|
| 간절곶 (울산 울주) | 35.3600 | 129.3603 |
| 호미곶 (포항) | 36.0776 | 129.5673 |
| 정동진 (강릉) | 37.6906 | 129.0347 |
| 고성 통일전망대 (강원) | 38.5836 | 128.3628 |

2026년 365일을 하루씩 재서 1등을 찾으면 이렇게 옮겨 다닌다.

| 기간 | 1등 | 일수 |
|---|---|---|
| 1월 1일 ~ 2월 20일 | 간절곶 | 51일 |
| 2월 21일 ~ 4월 20일 | 호미곶 | 59일 |
| 4월 21일 ~ 6월 11일 | 정동진 | 52일 |
| **6월 12일 ~ 7월 2일** | **고성 통일전망대** | **21일** |
| 7월 3일 ~ 8월 24일 | 정동진 | 53일 |
| 8월 25일 ~ 10월 23일 | 호미곶 | 60일 |
| 10월 24일 ~ 12월 31일 | 간절곶 | 69일 |

**남 → 북 → 남.** 하지를 꼭짓점으로 올라갔다 내려온다. 고성이 1등인
기간이 21일로 제일 짧다.

순서가 완전히 뒤집히는 것도 확인된다.

```
동지  간절곶 07:28 · 호미곶 07:29 · 정동진 07:36 · 고성 07:41
하지  고성 05:03 · 정동진 05:03 · 호미곶 05:06 · 간절곶 05:08
```

## 새해 일출은 1분 차이

1월 1일 — **간절곶 07:32, 호미곶 07:33.** 1분이다.

두 곳이 서로 '가장 먼저'라고 걸어놓은 다툼의 실체가 이 1분이다.
그리고 두 달만 지나면 순서가 바뀐다.

## 훅

```
1월 1일 · 간절곶 07:32
        · 호미곶 07:33

  1분

두 곳이 다투는 차이
```

## 화면

동해안을 세로로 세우고 **1등 표시가 해안선을 따라 오르내린다.**
계기판은 날짜, 아래에 네 곳의 일출 시각이 분 단위로 서고 1등만 밝다.

이 채널에서 처음으로 **순위가 뒤집히는 것 자체가 그림**이 된다.
지금까지는 값이 커지거나 선이 그어졌는데, 여기서는 네 줄의 순서가
바뀐다.

썸네일로 쓸 장면이 둘이다. 하나는 하지 언저리 — 1등 표시가 제일 북쪽
고성에 가 있고 간절곶이 꼴찌인 화면. 겨울 그림과 정반대라 나란히 놓으면
한눈에 뒤집힌다. 다른 하나는 마무리에서 독도가 켜지는 순간이다.
**후자를 쓴다** — '독도'가 썸네일에 있으면 클릭 이유가 하나 더 붙고,
본문을 봐야 왜 독도인지가 풀린다.

## 마무리 — 두 단으로 뒤집는다

먼저 육지 넷의 몫을 세운다.

```
간절곶   120일
호미곶   119일
정동진   105일
고성      21일
```

여기까지가 본문이 증명한 것이다. 그리고 화면이 물러서면서 동쪽 바다에
점 하나가 켜진다.

```
독도    365일

넷이 나눠 가진 한 해, 독도는 한 번도 안 내준 자리
```

**독도는 365일 전부 1등이다.** 육지 1등을 최소 4.9분(12월 23일,
간절곶) 최대 10.7분(8월 24일, 정동진) 앞선다. 경도 131.87도라
위도 효과가 못 이긴다.

앞의 다툼이 클수록 이 뒤집기가 커진다. 1분을 두고 다투는 장면으로
열고, 그 다툼이 통째로 무의미했다는 것으로 닫는다.

## 제목

```
간절곶과 호미곶, 둘 다 맞는 말이었던 이유
```

- 대안: `해가 가장 먼저 뜨는 곳이 한 해에 여섯 번 바뀌는 나라`
- 반전을 앞세운 것: `간절곶도 호미곶도 1등을 한 적이 없다`
- 무난한 것: `새해 일출, 간절곶과 호미곶의 차이는 1분`

첫 번째를 쓴다. 다툼이 있다는 걸 아는 사람은 답이 궁금하고, 모르는
사람은 무슨 다툼인지가 궁금하다. 양쪽 다 클릭할 이유가 생긴다.

## 확인한 것과 계산한 것

**기록값** — 네 곳의 위경도.

**계산값** — 일출 시각과 1등이 바뀌는 날짜 전부. NOAA 알고리즘,
고도 -0.833도 기준.

**밝혀야 할 것 — 지평선을 어디로 잡느냐로 몇 분이 움직인다.**
-0.833도는 평지에서 바다를 볼 때다. 실제 해맞이 명소는 해발이
조금씩 다르고 앞에 섬이나 산이 있으면 더 늦어진다. 화면의 숫자는
'같은 조건으로 계산한 값'이지 그날 그 자리에서 잰 값이 아니다.
다만 **순서가 바뀌는 사실은 몇 분 오차로 안 뒤집힌다** — 동지와
하지의 순서가 완전히 반대라서다.

**섬을 언제 넣는지가 이 편의 구조다** — 본문은 육지만 본다. 섬을
처음부터 넣으면 사철 독도라 순위가 안 바뀌고 편이 없어진다. 그래서
본문에서 '육지'라고 못 박아 두고, 마무리에서 그 단서를 걷으며
뒤집는다. 숨기는 것이 아니라 순서를 정하는 것이라, 본문 자막에
**'육지'**를 계속 붙여 둔다.

**연도** — 2026년으로 계산했다. 해마다 하루 이틀 움직인다.
