# 11편 기획 — 조선왕릉 100리

## 질문 한 줄

**조선 왕은 죽어서 어디에 묻혔나.**

풍수가 어떻고 석물이 어떻고는 다 다른 편이다. 이 편이 답하는 것은
거리 하나다.

## 데이터부터 확인했다

9편에서 정한 순서를 그대로 지켰다. 설계 전에 데이터.

국가유산청(khs.go.kr, heritage.go.kr)은 이 환경에서 응답이 없다(000).
대신 **위키데이터 SPARQL**이 열려 있어 거기서 받았다.

```sparql
SELECT ?t ?ko ?coord WHERE {
  ?t wdt:P361 wd:Q495276 .        # Royal Tombs of the Joseon Dynasty
  OPTIONAL { ?t wdt:P625 ?coord }
  OPTIONAL { ?t rdfs:label ?ko FILTER(LANG(?ko)="ko") }
}
```

19행이 나왔고 홍유릉이 두 번 잡혀 있어 좌표로 합치면 **18곳**이다.
유네스코 등재 기준(40기 18개소)과 맞는다.

## 가설을 먼저 검증했다

설계에 들어가기 전에 '100리 규칙'이 실제 좌표로 성립하는지부터 쟀다.
안 맞으면 편 전체가 무너지는 전제라서다.

경복궁 근정전(126.9770, 37.5796)에서 대권거리로 재고 1리 = 392.7m
(주척 기준)로 환산했다.

| 거리 | 리 | 능원 |
|---|---|---|
| 3.6km | 9리 | 정릉 |
| 7.5km | 19리 | 의릉 |
| … | … | (열다섯 곳이 100리 안) |
| 32.0km | 82리 | 파주 장릉 |
| **40.9km** | **104리** | **융건릉** |
| **63.0km** | **160리** | **영녕릉** |
| **137.2km** | **349리** | **영월 장릉** |

**열여덟 곳 중 열다섯이 100리 안이다.** 가설이 성립했고, 벗어난 셋이
각각 다른 이유를 갖고 있다. 그게 이 편이다.

## 규칙의 근거

『경국대전』 — **능역은 도성에서 10리 밖 100리 안**.

이유가 중요하다. **왕이 당일 다녀올 수 있는 거리**다. 능행(陵幸)은 왕이
직접 가는 것이라 왕복이 하루에 되어야 했다. 100리는 풍수가 아니라
일정표에서 나온 숫자다.

## 벗어난 셋

**융건릉 104리** — 1789년(정조 13) 10월 16일, 정조가 양주에 있던
아버지 사도세자의 묘(영우원)를 수원으로 옮겨 현륭원이라 했다. 겨우
4리 초과라 '거의 경계'다.

**영녕릉 160리** — 1446년 소헌왕후가 승하하자 광주(현 서울 서초구
내곡동) 헌릉 서쪽에 세종의 능을 조영했다. 거기는 40리, 규칙 안이다.
**1469년(예종 1) 여주로 천장**하면서 160리가 됐다.

**영월 장릉 349리** — 1457년(세조 3) 단종이 노산군 신분으로 죽자
영월 호장 **엄흥도**가 시신을 몰래 거두어 동을지산 기슭에 묻었다.
1681년(숙종 7) 노산대군으로 추봉되고 **1698년(숙종 24) 복위되어
능호를 장릉이라 했다.** 죽은 지 241년 뒤다.

## 셋을 나란히 놓으면 규칙이 하나 더 나온다

| | 처음 자리 | 지금 자리 | |
|---|---|---|---|
| 영릉 | 헌릉 서쪽 40리 | 여주 160리 | 옮겨서 나감 |
| 융릉 | 양주 영우원 | 수원 104리 | 옮겨서 나감 |
| 장릉 | 영월 | 영월 349리 | **한 번도 안 옮김** |

**규칙 밖으로 나간 능은 처음부터 거기 있던 게 아니라 옮겨진 것이다.**
장릉만 빼고. 그건 옮긴 게 아니라 **옮기지 못한** 것이다.

## 화면

지도 위에 **한양을 중심으로 100리 원**을 그린다. 이 채널에서 처음으로
화면에 '규칙'이 도형으로 선다. 능이 켜질 때마다 그 원 안인지 밖인지가
눈으로 판정된다 — 설명이 필요 없다.

계기판은 연도가 아니라 **리**다. 태풍 편이 hPa, 지진 편이 깊이였으니
전례가 있다. 질문이 '어디에'라서 거리가 축이 되는 게 맞다.

## 확인한 것과 계산한 것

**기록값** — 좌표는 위키데이터, 연도와 사건은 기록이다.

**계산값** — 거리와 리는 전부 계산이다. 대권거리로 재고 1리를
392.7m로 환산했다.

**밝혀야 할 것 — 리의 길이가 하나가 아니다.** 조선의 1리는 시기와
기준척에 따라 달랐고, 대한제국 때 0.4km로 정해졌다. 주척 기준
392.7m를 쓰되 화면에 '계산값'으로 밝힌다. 100리를 40km로 잡든
39.27km로 잡든 이 편의 결론(셋이 밖)은 안 바뀐다.

**기준점도 계산의 일부다** — '도성에서'의 기준을 경복궁 근정전으로
잡았다. 성벽 어디로 잡느냐에 따라 몇 리가 움직인다. 그래서 안쪽
경계(10리)는 화면에서 다루지 않는다. 정릉이 9리로 걸리는데, 그건
기준점을 어디로 잡느냐에 좌우되는 차이라 주장할 수 없다.

**적지 않은 것** — 북한 개성의 제릉·후릉 둘은 유네스코 등재에서
빠졌고 좌표도 확인하지 못해 이 편에 없다. 함경도의 추존 4대조 능
여덟도 조선 개국 이전이라 뺐다. 화면은 남한의 열여덟 곳만 말한다.
